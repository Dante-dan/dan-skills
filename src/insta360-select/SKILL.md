# Insta360 Select：Studio 选镜

把真实全景素材整理为可供创意剪辑使用的镜头包。可以独立调用；只完成用户指定的选镜/导出范围，不因选镜授权而启动成片、云上传或清理。整轮制作由 [insta-cut](../insta-cut/SKILL.md) 串联到 [insta-edit](../insta-edit/SKILL.md)。

## 选镜判断

按 [选镜规则](references/selection-rules.md) 执行“看素材→事件→故事候选→按作用选镜→排成序列回看”，必要时改主线重选。通常比较2–3条有真实证据的故事，不足就如实写；每个入选镜头必须说明**它在这个位置为观众增加了什么**及删除损失。以段落而非整个文件评判，优先保留唯一事件/反应候选，再比较同职责备选的技术质量。只在需解释取舍时读 [理论依据](references/editorial-foundations.md) 和 [正反案例](references/selection-cases.md)，不固定数值权重。

## 执行路径

1. 读取用户指定日期/目录、项目状态和已有 `selection.json`，确认哪些来源和镜头已看过，复用有效记录。识别拍摄日和真实源文件名；不以当前日期替代拍摄日，不要求已清理的旧原片重新存在。
2. 用本机会话支持的应用控制操作Insta360 Studio，检查实际媒体/云相册和下载状态，核对源规格；不要假设版本固定按钮、云接口或导出功能。操作细节、空间控制、取景及历史辅助参数按需读 [Studio选镜执行](references/studio-selection.md)。完整本地INSV检查容器/稳定性和实际镜头/音频尾部；下载缓存不标完整。
3. 看连续片段，按有意义区段建立带时间码的事件和覆盖日志，分开记录可见事实/推测及画面/音频覆盖；联系表只定位。先提出有事件证据的故事候选并比较开头问题、真实兑现、观看回报和分享理由，再按hook/context/development/evidence/reaction/payoff/transition/pause等作用挑镜。抽帧或未听音如实记，不能凭缩略图、漂亮程度或猜测写完整故事。
4. 在Studio里为候选镜头选择朝向、FOV、画幅及当前支持的重构/关键帧，利用拼接和FlowState，保留空间关系。为剪辑留前后余量，保留不同故事/视觉概念的候选，避免一开始只给一种节奏。成人全部列为后续遮挡目标，前景/背景和镜头边缘都记录；此阶段不声称隐私处理已完成。
5. 在用户已授权选段导出的范围内，只导出选中段的高质量普通视角，尽量一次重构，保留原声和准确约60帧时基。原始帧率先probe，59.94用 `60000/1001`、真60用 `60`；原片120fps不能误按60fps解释为慢动作。4K重构的源质量限制如实记录，代理不作为最高画质来源。用户仅要挑镜时可只交时间码，不自动渲染大文件。
6. 镜头排成序列后复查故事、承诺兑现、前后组合及动作/信息/情绪节奏，必要时只退回受影响故事/镜头重选，保存备选/淘汰理由和未审项。按 [交接约定](../insta-cut/references/handoff.md) 输出 `selection.json`，区分 `candidate / selected / export_pending / ready_for_edit`，给出源入出点、取景、故事作用、成人风险、原声观察和最高质量可用文件。复检实际导出头尾、时长、画幅和音轨，不把排队当已导出。

## 边界与交付

按制作日记录镜头包和Studio项目位置，源片按拍摄日组织；只有实际生成且检查可用的选段才标 `ready_for_edit`。界面或导出受阻时记录具体缺项，保留已完成镜头，不无限重试；FFmpeg单鱼眼辅助路径必须注明未经Studio完整拼接/FlowState，不能冒充同等结果。

独立选镜的交付是镜头清单、可用选段、源依赖及候选故事；不擅自推进剪映成片、发布、云上传或删除。总流程已明确授权的原片备份可并行，由insta-cut记录；云核对只查目标目录唯一文件名，不下载验证。资料更新按 [三技能维护](../insta-cut/references/skill-maintenance.md) 提交到dan-skills；家庭素材、截图和运行清单留项目。
