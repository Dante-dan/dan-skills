# Studio 选镜与取景执行

## 先用实际画面建立素材地图

核对当前账号和本地素材/云相册来源，不凭文件名猜事件。仅操作用户指定日期或批次，已归档旧原片不存在不要求重下。先看当前Studio实际提供的媒体/云相册界面，读取日期、时长、分辨率、帧率及下载状态；界面没有的功能不猜入口。没有可操作的Studio窗口时记录阻塞，继续可独立进行的本地规格盘点，不声称已经完成Studio选镜。

先低成本定位，再围绕动作、视线、声音和互动看连续片段。联系表要有源文件名和时间码，只用于定位，不替代连续观看。寻找开场钩子、完整动作、反应、连接动作、环境空镜和结尾余韵；记录不同故事可能性，给后续创意剪辑保留选择，而非只截零散可爱瞬间。听音能力不足时原声记录为未听/待确认，不猜对白、情绪或歌词；不因此伪报完整声画观察。

## 完整原片与本地空间

对实际本地INSV核对容器、镜头流、音轨、文件稳定性和尾部可解码；双鱼眼时检查两路尾部，不把下载中的缓存当完整素材。具体镜头流数量按实际相机规格确认。只读完整性检查与云备份核对分开：云端按唯一文件名核对即可，不做云哈希或下载验证。

算剩余空间后按候选片段导出，避免预先生成整批4K球面视频。完整原片可由总流程先启动私有备份，与本阶段并行。独立选镜调用只记录备份交接，不擅自上传、删除、购买空间或重新注册下载任务。

## 在 Studio 里重构候选镜头

1. 打开目标源片，核对镜头朝向、地平线、拼接缝、机身/自拍杆和画面边缘。试横竖画幅，保持动作方向和视线关系。
2. 在当前Studio支持的功能中使用拼接、FlowState及重构/关键帧；根据主体运动设置视角、FOV、俯仰和过渡。用实际预览检查跟随速度，不让镜头追赶造成晕动。先确认当前客户端存在的选项，不编造固定按钮坐标或API。
3. 同时挑主体近景、父母跟随视角、反应与可用空镜。全景同一时刻两个视角属于同一事件，记录同一时间来源，不当作两个先后事件。
4. 候选区段留前后剪辑余量，记录真实源入出点、帧率、画幅、取景参数/关键帧及Studio项目位置；记录前景/背景可辨成人和遮挡风险，儿童保留真实面部。选镜阶段不声称已完成成人匿名化。
5. 获授权选镜导出时，先对最难运动/暗部的一小段验证，再用当前Studio支持的高质量设置输出选中区段，保留原声、正确约60帧时基和可追溯时间码。4K重构不等于原始拍摄细节达到4K，升采样如实记。导出后核对实际尺寸、时基、时长、头尾和音轨映射，不能只看界面选项。

## 历史单鱼眼辅助路径

以下只为2026-10-19一批素材的本机实测参数，不是新相机默认值；不能冒充已在Studio拼接/FlowState。

该批 INSV 两路 1920×1920 鱼眼、120000/1001 fps 和原声音轨。优先 Studio 拼接、FlowState、重构后导出；两个相机方向可形成孩子近景与父母跟随视角，保持空间、时间关系。

Studio 无法导出时可 FFmpeg v360 直接取单鱼眼平面视角，不等于完整360拼接，也不提供 Studio FlowState。该批常需 hflip,vflip 才正向，不对新相机盲用。低成本测试双镜头、方向、俯仰、FOV，观察运动连续性。

本批竖屏示例，需按实际镜头替换角度与 FOV：

```text
fps=60000/1001,hflip,vflip,
v360=input=fisheye:output=flat:ih_fov=200:iv_fov=200:
h_fov=100:v_fov=129.5:yaw=0:pitch=0:reset_rot=1:w=1080:h=1920:interp=lanczos,
hqdn3d=1:1:2.5:2.5,scale=2160:3840:flags=lanczos,setsar=1
```

vFOV = 2*atan(tan(hFOV/2)*height/width)，注意弧度换算，不按宽高比线性放大。横屏可先测试1920×1080、hFOV约112、向上pitch约25，再输出3840×2160。去畸变后升采样必须披露，避免过量放大。M4 Max可用 hevc_videotoolbox 做中间片、H.264 MP4 交付，先确认具体工具支持。

核对独立音轨映射 `-map 0:a:0?`；实时节奏应正确丢帧到59.94并维持原声长度，不误将120fps直接解释成60fps慢动作。


## 输出

把镜头和缺项写入 `selection.json`，按 [交接约定](../../insta-cut/references/handoff.md) 输出。保留Studio项目和源时间码，联系表、代理与高质量选段分开。工具受阻且无授权替代时交付部分清单并标 `export_pending`，不把单鱼眼替代当完整360拼接。
