# 剪辑取舍、故事与注意力：理论到判断

用于需要解释选镜依据或比较难以取舍镜头时；日常执行直接读 [选镜规则](selection-rules.md)。这是从理论到本工作流的应用设计，不是经实验验证的评分器。来源类型、查阅状态及14项参考见 [来源](editorial-sources.md)。本用户仍创意第一、叙事第二；下列原则帮助创意形成观看效果，不把创作改为固定剧情模板。

| 理论及来源 | 可迁移的判断 | 本工作流如何应用；边界 |
| --- | --- | --- |
| Walter Murch：六原则，情绪→故事→节奏→视线→二维画面关系→三维空间连续性；[书籍摘录，Berkeley课程页](https://blogs.ischool.berkeley.edu/i290-viznarr-s12/the-rule-of-six-walter-murch/) | 一次切镜冲突时，优先考虑观众感受和表达，而不只追求技术连续 | 对每个镜头写观众获得的感受/理解、删除损失、与前后镜的效果。原文百分比是作者示意，不是统计权重，不生成镜头总分。人在大笑不等于观众必然感动；观众感受是待实际审阅的创作假设。 |
| Story Spine/Story Beats；[Pixar × Khan Academy课程](https://www.khanacademy.org/computing/pixar/storytelling/story-structure/v/video1a-fine?t=233) | 节拍中的决定、变化和因果构成推进，不是步骤名的堆叠 | 区分主题、内容清单、一句话变化及表达角度。课程采用故事骨架，并非Pixar原创发明；安静日常可用观察—发现、前后差异、重复中的变化，无需伪造冲突。 |
| Loewenstein信息缺口；[1994论文](https://doi.org/10.1037/0033-2909.116.1.75) | 对已知与想知道之间缺口的意识可激发好奇 | 把开头写成已知背景、具体问题、未揭示信息及真实兑现镜头四项。它是应用建议，不是论文提供的短视频留存公式；没有真实答案就收窄承诺或换故事，不能补造结果。 |
| 库里肖夫效应教学与Eisenstein蒙太奇；[Adobe](https://www.adobe.com/in/creativecloud/video/discover/edit-a-video.html)、[BFI](https://www.bfi.org.uk/features/where-begin-sergei-eisenstein) | 意义由相邻镜头共同产生，排序能改变理解 | 主动试预期/结果、动作/反应、环境/细节、同构图/不同状态、多次尝试等关系。类比与事实因果分开；不把异时表情拼成真实反应，不能把教学示例当本片事实证据。 |
| Karen Pearlman节奏工具；[出版社配套资源](https://routledgetextbooks.com/textbooks/9781138856516/resources.php) | 时机、推进速度、运动轨迹的成句帮助组织节奏 | 本工作流再分动作、信息、情绪三层，设计等待/变化/释放和停顿；三层检查是应用框架，不宣称作者原文给出此表。音乐拍点只是一条线索，不决定每刀。 |
| Berger & Milkman传播研究；[作者托管论文](https://jonahberger.com/wp-content/uploads/2013/02/ViralityB.pdf) | 情绪唤醒、惊讶、有趣与实用价值可帮助提出分享假设 | 在故事层写“什么观众会发给谁、为什么”，不逐镜打传播分。研究包含新闻传播与实验，不是当下短视频推荐模型，不预测爆款概率、不套固定算法权重，也不为唤醒情绪破坏真实关系。 |

镜头的技术质量在同一职责的备选之间比较；唯一真实反应或因果桥梁先进入候选池，再检查可读性、修复或替代方案。信息、理解、期待、情绪、空间、视觉观念或有意停顿都可以是贡献；无需每镜推进情节。无任何可说明的贡献时才降低优先级。创意来自顺序、观察角度、镜头组合及图层/声音设计，不只依赖装饰数量。
