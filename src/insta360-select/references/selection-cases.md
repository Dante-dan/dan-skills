# 带上下文的选镜正反案例

以下均为合成教学情境，不是真实家庭素材或已实机审过的片。应用时替换成实际文件、时间码及相邻镜头；不能把示例事件添加进用户原片。

| 素材与目标 | 入选 / 淘汰备选及理由 | 前后组合与复查 |
| --- | --- | --- |
| 只拍到一次失败拉花，没有第二次尝试；目标记录初次体验 | 留失败成品及同次真实反应；拒“重试终于成功”主线和无证据的成功预告 | 准备→关键动作→失败→真实回应；开头问“第一次能画成什么”，结尾接受实际结果。不能以另日漂亮成品兑现。 |
| 人物发现新玩具；有轻微晃动的唯一惊喜与漂亮但重复的静物 | 关键反应先留候选，再查可读/隐私；静物可只留一个用于交代，不因画质排序把事件删光 | 目光→玩具→同次反应。不能使用隔天笑脸当此刻反应；不能凭笑脸断言内心想法。 |
| 修好物品；两段漂亮旋转展示都说明“已完成” | 留更能证明修复结果的一段；另一段同职责、无新视觉/情绪贡献则淘汰 | 早先损坏细节→操作→功能验证；旋转展示不能代替真正功能验证。 |
| 结果很精彩，但递工具的普通中景解释是谁帮助 | 留必要铺垫，删掉会让后面协作关系突然出现；拒只拼全部高潮特写 | 求助/递工具→完成→回应。技术普通不等于无价值，眼神/动作关系要可理解。 |
| 完整关键操作需看清手势，音乐每拍都有标点 | 保留可理解的关键动作，准备步骤可压缩；淘汰只为全踩点而打断操作的切法 | 压缩准备→等待操作→结果看清→放松；自动节拍只是辅助，不决定每刀。 |
| 安静散步，无失败或成功；有脚步变慢和回头等待 | 留步伐差异与真实回头，故事可为“走慢一点一起看”；拒为制造冲突拼接别时皱眉 | 环境→步伐→等待→同行；停顿增加关系理解，不能因无新增台词就删光。 |
| 地图与鞋印形状可匹配，目标偏创意的探索片 | 可留构图普通却能组成尺度/形状联想的镜头；不能只因不推进剧情淘汰 | 图案→真实鞋印→人物前进；注明这是视觉类比，不暗示两地点实际同一位置。 |

比较时写“观众在这里增加了什么”与删除损失；不要给漂亮镜/晃动镜永久高低排名。同一素材在教程、失败重试或生活仪式主线中，职责和选法会不同。
