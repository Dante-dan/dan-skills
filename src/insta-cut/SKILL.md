# Insta Cut：选镜与剪辑的总流程

兼顾创意与叙事，自主完成可播放版本供用户看结果。人物影片先从具体行动里找新的起因、变化和结果，再设计剪法；不默认套编号章节，按 [人物故事与去模板化](../insta-edit/references/sequence-design.md#人物故事与去模板化) 执行。此skill负责阶段编排、交接、日期组织、归档及用户确认；Studio镜头操作和剪辑实现分别由两个专用skill负责，按阶段加载，不一次读全部技巧库。

## 先判断接续阶段

读项目 `WORKSTATE.md`、来源/下载、`selection.json`、剪辑、审片及归档记录，优先最新真实用户要求。已交付影片不因定时消息重剪；已删除的旧原片不要求重下；仅备份/清理时不启动选镜或剪辑。没有项目状态时在用户工作目录建立制作日记录，不把家庭素材和运行状态写进技能仓库。

- **Studio挑镜头/从INSV找故事**：读取 [insta360-select](../insta360-select/SKILL.md)，实际看片、挑区段、重构和导出，生成镜头交接清单。
- **已有镜头/普通视频待剪辑**：读取 [insta-edit](../insta-edit/SKILL.md)，直接进入创意分镜、剪映制作、审片和导出；已有可用清单不重复选镜，普通视频不强制经过Studio。
- **整轮制作**：先选镜再剪辑。完整原片和侧车先启动已授权私有Drive归档，备份与选镜/剪辑并行，不等待上传结束才制作。每阶段输出见 [交接约定](references/handoff.md)。

若只安装本skill而缺少子skill，先定位同仓库/已安装入口；缺失时明确指出缺项，不假装执行或以旧兼容文档代替完整子skill。用户要求安装时再按已授权流程安装；当前仓库三个skill一起维护。

## 串联与交付

1. 确定拍摄日、制作日和本轮范围；沿用 [日期组织](../insta-edit/references/production-workflow.md#日期组织实际落盘与迁移)。源片、代理、选段、草稿、素材、预览与 `YYYY-MM-DD cuts/` 分层保存，同一文件一个规范本体，其他入口用软链/索引；真实剪映draft仍由应用管理，制作日保存位置索引。
2. 按“覆盖与事件→通常2–3条有证据的故事候选→选定主线→按作用选镜→序列回看”的循环接手。检查开头是否有真实兑现、每镜在此处增加什么、动作/信息/情绪节奏是否合适；不支持多个故事时不凑数。选镜输出的六项记录见 [交接](references/handoff.md#故事与选镜记录扩展)。从选镜清单中挑实际支持的故事/视觉线索交给剪辑；选镜只提出候选，不提前锁死创意。清单缺时间码、可用高质量片段或源依赖时退回补齐相应镜头，不重做已完成镜头。清单无效或仅代理时不能直接当最高画质来源。
3. 剪辑阶段沿用普通平面视频、最高可用画质4K约60帧、原声和自然肤色；所有可辨成人用可爱纯动物3D头像遮挡，儿童真实。使用剪映和当前安装的 `jianying-editor`，不用HyperFrames。具体取景、头像、声音、技巧和编码检查归子skill，不在此复制一套参数。
4. `insta-edit`可导出待审预览；只有当前版本实际通过独立审片和交付检查才认定成片。未具备完整看/听能力时保留真实待审项并结束本轮，不循环等待；技术检查不冒充全片审查。审核豁免只按用户明确范围记本轮，不扩为永久豁免。
5. 交付当前可播放版本与简短创意说明，记录用户对**该版本**的确认。独立agent通过、导出成功和上传排队都不是用户OK。内容改动后重新审当前版本，不能继承旧片认可。
6. 按 [私有云归档与清理](references/drive-archive.md) 处理成片、原片和侧车；默认本地留成片，剪映私人云空间及Drive各备份。原片/侧车 → `My Drive / Insta360 / 原片 / YYYYMMDD / 内容`（拍摄日）；成片 → `My Drive / Insta360 / 成片 / YYYYMMDD / 人类可读文件名`（制作日）。核对实际云目录中唯一完整文件名一次，记 `name_verified`并复用；不反复查hash/大小/版本、不下载/恢复验证。这项轻量规则不取消本地素材完整性或成片审片。
7. 用户明确确认当前成片且对应备份文件名核对完成后，才按准确白名单删除授权本地原片。成片/草稿额外清理只按用户本次明确范围，保留其他影片与共享依赖；不unlink Drive同步路径、不删云原片或Insta360云相册，不把移入本地Trash当实际释放空间。记录实际释放量和保留项。

默认不公开发布或创建共享链接。用户另明确指定版本和抖音等目的地时，记录独立授权；优先用剪映导出成功页的交接入口，核实按钮实际作用，只获上传授权时保留编辑页而不最终发布。用户已自行发布的版本不重复上传/发布。

## 平台适配与反馈

平台、题材、目标观众、观看回报、分享理由、节奏偏好按 [平台与反馈](references/platform-feedback.md) 传给两个子skill。平台标签不替代具体创作目标；保留可选替代开头与假设，用户提供实际数据后再做有限比较，不预测爆款概率、不自动发布A/B或重剪历史片。仅归档时不启动这一制作循环。

## 按需使用代理与维护

可委派素材侦察、素材/许可研究、故事或视觉/声音方案，独立文件输出；同一时间轴只由一个主剪写入。剪辑skill安排未参与制作的独立审片agent，真实检查当前片；选镜清单通过不能替代成片审阅。沿用既有检查任务，不自行新建或重启已关闭计划；全部授权工作结束后关闭原任务。
