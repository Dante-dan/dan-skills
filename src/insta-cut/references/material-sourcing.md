# 素材侦察与补充素材

在看过原片、提出具体缺口之后读取本文件。目标是补足空间、动作、情绪或声音的连接，不用素材数量衡量剪辑质量。网站与许可核验日期：**2026-10-20**；每次实际选用仍打开单条作品页及当前许可重新核对。

## 先从自己的原片找 B-roll

1. 先看带声音的原片，再做带文件名和时间码的 selects：环境远景、树影/水面/灯光、手脚细节、玩具、出发与收拾、父母反应、孩子目光、同一动作的另一镜头，以及可用的干净环境声。全景的背面和动作前后常有被漏看的素材。
2. 写下缺口的作用，例如“跑远以后需要一口气”“交代从白天到傍晚”“遮掉一句话里的跳切”。优先同场实拍；同日其他场景只有在空间、光线和时间关系成立时使用。
3. 原片仍无合适镜头，才列外部搜索单：想说明什么、需要几秒、景别/运动/方向/光线/比例、是否需要声画同步，以及是否会造成真实经历误解。没有明确作用的素材不下载。
4. 外部空镜可做明确的意象、章节卡、文字内景或抽象过渡；不能把外地日落、另一家庭互动、另一公园航拍剪成“我们当天就在这里”。纪实中的地点/天气/事件必须有原片或可靠记录支持。无法避免误解时用可识别的插画表达，或标明“意象画面”，或弃用。

## 实际搜索与筛选

每个缺口先试听/预览少量候选，形成 2–3 个可比较选项，再下载最终使用项及少量备用；不批量囤积。以下是搜索构造方法，不是必须套用的画面清单：

| 需要补足的功能 | 视觉关键词示例 | 声音关键词示例 |
| --- | --- | --- |
| 跑动之后的呼吸 | `sunlight leaves close up static`、`树影 微风 特写` | `park ambience light wind no voices` |
| 孩子触摸镜头的玩心 | 原片手指/镜头反光优先；必要时找抽象光斑而非别人的孩子 | `soft pop short dry`、`camera shutter single` |
| 白天走向夜晚 | 实际同地点光线变化优先，其他地点夜景只做明确意象 | `evening park insects distant traffic` |
| 段落连接/章节卡 | `paper texture subtle`、`sky negative space` | `gentle whoosh short`、`soft chime single` |
| 温馨但有前进感的配乐 | 不用画面搜索代替试听 | `warm acoustic instrumental`、`playful pizzicato light`、`gentle piano no vocals` |

- 视觉筛选：场景是否真实匹配、主体与留白、镜头运动方向、日夜/天气、色温、景深、粒子与压缩感、是否含醒目标识、是否有可辨认成人需要继续动物遮挡。能用无人物空镜时无需额外引入陌生人物。
- 声音筛选：场地远近、混响、声源方向、风噪底噪、是否含人声/音乐、前后留尾及是否可无痕循环。室内带长混响的脚步不直接铺在户外近景上。原声能完成动作表达时无需补拟音。
- 配乐先选情绪和编制，再看速度、段落、动态与结尾是否可剪；不要只按 BPM 选歌。轻松段落不必连续铺满，重要一句话、笑声或犹豫可以让音乐暂停。与声音设计参考联用。
- TikTok/Instagram/自媒体教程可以用于观察技巧与节奏；观看教程不构成搬运该作者视频、音乐、图片或模板的许可。复刻的是剪辑原理，素材重新合法获取。

## 适配项目技术规格

下载后对实际文件做 ffprobe/图像尺寸检查：原始像素、帧率准确分数、编码、色彩/HDR标记、音频采样率/声道和时长，别只信“4K”搜索标签。

- 横片优先能在裁切后覆盖 3840×2160 的视觉素材，竖片优先能覆盖 2160×3840；横图裁竖图要算有效剩余像素。低分辨率可用在有意设计的小窗、照片卡或文字内景，不能用升采样假称原生 4K细节。
- 成片按项目真实时基 `60000/1001` 或 `60`。外部24/25/30fps可短时按正常速度重复帧，也可在明确设计的照片/停格段落使用；慢动作仅在源帧率和动作允许时处理。不能把普通升帧或光流补帧说成拍摄时的60fps。补帧必须看手指、树叶、边缘与头像附近伪影。
- 先统一曝光/白平衡与色彩空间，再匹配饱和度、对比和颗粒。遇 HDR/SDR 混用做明确色彩转换，不能直接叠滤镜压出肤色或高光问题。图片动效留出足够像素和安全裁切余量。
- 音乐/音效尽可能拿原始 WAV/FLAC；按时间轴需求转为48kHz工作音频。转换采样率不等于提升原始音质。保留原文件，避免多次有损编码。

## 每个实际使用资产的许可证据

在项目 `licenses/assets.json` 记录下表字段，并保存合法可获取的许可页/下载证书快照；令牌、登录 Cookie、临时签名URL不要进记录或Git。候选未使用项可简记，不必装成最终授权清单。

```json
{
  "asset_id": "平台内作品ID",
  "title": "作品名称",
  "creator": "作者及作者主页",
  "source_page": "作品详情页永久URL",
  "provider": "Freesound / Pexels / ...",
  "license_name": "CC BY 4.0 / 平台许可名",
  "license_url": "对应版本完整许可URL",
  "verified_at": "ISO8601核验时间",
  "evidence_file": "licenses/证据文件相对路径",
  "permitted_use": "本片用途、平台与改编允许范围",
  "attribution_required": true,
  "credit_text": "作者、作品、来源、许可链接及修改说明",
  "restrictions": [],
  "downloaded_file": "assets/external/相对文件名",
  "sha256": "实际下载文件哈希",
  "modifications": "裁切/调色/节选/变速等",
  "timeline_usage": [{"story": "故事名", "in": 0.0, "out": 1.0}],
  "diegetic_status": "现场实录 / 补充拟音 / 外部意象"
}
```

CC 署名按作品名（可提供时）、作者、来源、**确切许可版本和链接**、改动说明组织，不暗示作者参与或背书。CC0一般无需版权署名但仍记录来源。遇 CC BY-SA 要评估具体改编及交付兼容性；不明确就选可用替代品。ND通常不适合需要同步/改编的音乐或视觉设计，不凭“只用几秒”跳过条款。[Creative Commons 官方复用指引](https://creativecommons.org/reusing-cc-licensed-content/)、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)、[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)、[CC0](https://creativecommons.org/publicdomain/zero/1.0/)。

交付 `CREDITS.md` 和许可清单，与对应日期成片目录及备份同行。需要署名的条目按许可在影片、播放页说明或随片说明等合适位置**实际提供**；不能只在私有工作目录写一份然后删掉片尾署名。用户希望片尾更简洁时，优先换成条款允许免署名的素材，或用短而可读的署名卡并保留完整说明，不把署名缩成看不见。

家庭原片保持本地处理。搜索只提交场景词与技术要求；不向素材网站、未经授权的 AI/模板服务上传家庭视频或儿童肖像换取效果。用户已授权的剪映云空间、Google Drive备份按归档流程执行，不等于授权上传给任意素材或AI网站。
