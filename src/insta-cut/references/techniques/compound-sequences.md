# 正片推进与动作高潮

本页属于[R01–R12组合配方](compound-recipes.md)，只加载目标条目。它们使用C/T基础能力组成完整设计，未新增“已经跑通”的API或预设；参数为分镜起点，真实执行先做难点样片。

<a id="r05"></a>

## R05 时间标本展开再追赶

**组合链**：定格停顿＋多时刻动作抽样＋路径解释＋受控加速追回。

- **位置与动机**：正片动作高潮；一次飞盘、跳跃或触碰有值得看清的中间状态。
- **素材门槛**：需要连续源帧、动作起终点、可压缩的非关键过程与分离的原声；不是任意延长纪实反应。
- **图层（由上到下）**：上：少量时间/方向标记；中：已遮挡的多时刻主体残影；下：干净底图/主镜。恢复后切回独立连续片，不让残影挂满整段。
- **动作顺序与节奏**：在动作前短暂建立连续运动；顶点停约半秒，2–3个姿势按时间出现；顶点接触声只播放一次，停留期保留连续环境声；恢复时加速非关键段，回到原定乐句落点。接触帧保持完整，其声音按新的画面事件时间重新对齐，不复制接触声或拉伸对白来填暂停。
- **实际路径**：各姿势记录真实源时间，最后一张与恢复视频帧对应；剪映曲线/分段恒速先实测，无法可靠追回就延长段落而非丢帧硬追。所有残影和动物头像一同变速。
- **质检与降级**：重复播放同一次接触、源时间倒序未提示、背景穿洞、音频随画面无意变调。减为三阶段静帧解释，或只留一次短慢动作。
- **调用基础能力**：[C21](advanced-freeze-time.md#c21)、[C24](advanced-freeze-time.md#c24)、[C27](advanced-freeze-time.md#c27)；原理来源随对应条目读取。

## R06 错时窗口追逐，反应接管

**组合链**：主事件连续片＋延迟反应PiP＋窗口轨迹＋同义构图合并。

- **位置与动机**：正片因果关系；孩子做一个动作，父母或同伴稍后有可验证反应。
- **素材门槛**：有真正对应的动作与反应，不用无关笑脸改写关系；错时并置必须让观众读懂回看/反应。
- **图层（由上到下）**：上：必要的“随后/回看”等短提示；中：反应窗口与边框；下：主事件。反应接管后主事件退出，音轨主次跟随视点。
- **动作顺序与节奏**：主事件先独立发生；反应开始时小窗沿主角目光或留白方向进入；窗口短暂停住让反应被读懂，再扩成全屏；下一镜完成这次反应而非马上切走。
- **实际路径**：窗口的路径与放大分开两阶段，扩大前先到稳定落点；反应源时间独立于底片，不错误强求两者同帧。接管只要求小窗与其全幅反应源同帧。
- **质检与降级**：像真实同步多机位却其实错时、两路音轨互抢、窗追着人脸挡表情。用明确“随后”或取消错时，退回动作→反应顺剪。
- **调用基础能力**：[C30](advanced-keyframes.md#c30)、[C40](advanced-overlays-pip.md#c40)、[C41](advanced-overlays-pip.md#c41)；原理来源随对应条目读取。

## R07 全景视点接力的空间解释

**组合链**：同源360多取景＋方向线＋主次PiP＋反向构图校准。

- **位置与动机**：正片探索/跑动；需要同时理解孩子去向与父母相对位置。
- **素材门槛**：同一球面源、准确共同时间码、各方向有足够像素；两机位可以是虚拟取景，但不声称实际有两台摄影机。
- **图层（由上到下）**：上：有限方向标记；中：次视角小窗；下：主视角。两视角各自已有成人遮挡；保留一条共同原声，避免同源叠加。
- **动作顺序与节奏**：先主视角看动作起点；需要空间信息时打开次视角，方向线连接对应方位；主角穿过画面/视线转向时次视角接管；旧主视角退为短暂小窗后退出。
- **实际路径**：Studio分别输出同源同帧取景，剪映按准确源时间同步；用两视角都可辨认的一次接触/经过等事件做逐帧相位检查，不能只因文件时间戳相同就判同步。交接依据动作/目光而非突然180度甩镜。两路不同裁切不能靠简单几何贴合冒充同一视角。
- **质检与降级**：方向线不符合实际方位、接管后动作重复、广角脸变形或小窗太糊。改全景方位示意或只保留一个稳定主视角。
- **调用基础能力**：[C33](advanced-keyframes.md#c33)、[C36](advanced-keyframes.md#c36)、[C43](advanced-overlays-pip.md#c43)；原理来源随对应条目读取。

## R08 现场一声触发局部世界变化

**组合链**：真实声音瞬态＋局部视频蒙版＋图文包络＋连续正片。

- **位置与动机**：正片小高潮；拍手、碰到镜头、放下玩具或脚落地形成可靠触发事件。
- **素材门槛**：必须有可见接触帧与对应原声；先有真实事件，再设计短效果，不把脚步检测当自动导演。
- **图层（由上到下）**：上：一次性图文/边框响应；中：同时间局部特效层；下：自然V_safe。效果只改变局部色彩/纹理或窗口，不改变成人遮挡alpha。
- **动作顺序与节奏**：触发前保持平静；接触帧使局部窗口/边框短暂扩张；响应幅度随后衰减，约一秒内回归自然画面；下一动作获得完整时间。
- **实际路径**：人工确认瞬态和画面接触，再以有限关键帧包络驱动局部效果；本地分析可给候选点，但不能自动宣称对拍。不要让抖动、闪光、缩放、变速同时全开。
- **质检与降级**：音效先于动作、误把背景敲击当接触、肤色全变、尾效不归零。只保留真实声音和一次轻量视觉反馈，或完全取消包装。
- **调用基础能力**：[C35](advanced-keyframes.md#c35)、[C48](advanced-beats.md#c48)、[C49](advanced-beats.md#c49)；原理来源随对应条目读取。
