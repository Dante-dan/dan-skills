# 空间转场与时间桥

本页是[50项创意配方](creative-50.md)的一部分。路径M=剪映轨道/蒙版/关键帧手工组合，U=须核对本机实际UI，X=可能需要本地辅助预合成；均不代表已实机跑通。先读[执行与来源边界](creative-50.md#使用方式)，再只加载本次需要的条目。

## C09 轮廓变形匹配转场

- **场景与素材前提**：两镜物件轮廓相似，如圆盘接圆灯；需主体方向、位置、尺度可对齐。
- **实现路径**：M/X：先把轮廓对齐，再用一层短蒙版形变交接内部纹理；需要真正网格变形时预合成，不把简单交叉溶解说成morph。
- **失败征兆与替代**：边缘融化、不同人物五官互相变形、轮廓无法读懂；改轮廓对齐硬切。
- **区别/机制**：轮廓对齐 + 内部纹理替换。原理依据见[来源P04](creative-sources.md#p04)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C10 屏幕推入下一场

- **场景与素材前提**：画面里有手机、相框或展示牌；需屏幕平面可定位、下一镜能作屏幕内容。
- **实现路径**：M/X：先把下一场置入屏幕平面，跟随四角/透视，再逐渐把整个屏幕推满画幅；进入满屏才移除外框。无角点跟踪时用静机位四角预合成。
- **失败征兆与替代**：替换图越过边框、透视漂移、无限放大糊片；只做短屏内播放再硬切下一镜。
- **区别/机制**：平面替换 → 满屏交接。原理依据见[来源P04](creative-sources.md#p04)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C11 抓住画面把下一场拉进来

- **场景与素材前提**：手拉窗帘、拉衣角或拽纸张有真实力的方向；需干净接触边界。
- **实现路径**：M：下一场当可拖动整幅图层，前景手部/物件单独抠出压在它上面；随拉动同时移动图层与揭示蒙版，结束接下一场真实运动。
- **失败征兆与替代**：手与画面滑脱、方向相反、成人头像没跟随前景；退为沿实物边缘的简单擦除。
- **区别/机制**：前景接触层 + 被拉动画层。原理依据见[来源P01](creative-sources.md#p01)；具体组合为本工作流的编辑设计，非原教程逐步转录。

<a id="c12"></a>

## C12 狭缝扫描时间扭曲

- **场景与素材前提**：跑步或横向经过形成明显位移；需短稳定片段，不用于必须精确认知的人体动作。
- **实现路径**：X：把画面分成窄条，每条读取递增时间偏移，形成扫描波，再让偏移归零进入下一镜；须本地逐条预合成，输出时长有限。
- **失败征兆与替代**：肢体被拉成长条、观众眩晕、头像在时间片间错位；只对背景纹理使用，主体保留正常。
- **区别/机制**：空间切片 × 不同时间偏移。原理依据见[来源P04](creative-sources.md#p04)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C13 共轴旋转接力

- **场景与素材前提**：两镜都有可认知的中心物体或转动；需统一旋转轴和边缘余量。
- **实现路径**：M：两镜围绕同一归一化中心旋转，切点保持角速度同向；在运动较快处交接，不用每个镜头都转一圈。
- **失败征兆与替代**：旋转中心跳、角速度瞬变、画边露黑；改为角度小的同轴旋转或静态构图匹配。
- **区别/机制**：同轴 + 角速度延续。原理依据见[来源P02](creative-sources.md#p02)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C14 前中后景分层穿越

- **场景与素材前提**：场景有树叶、主体、远景三层；需可用分层遮罩或高质量抠像。
- **实现路径**：M/X：近景横移快、中景慢、远景更慢，近景掠过时揭示下一场；仅二维平面差速时称2.5D模拟，不声称重建真实三维。
- **失败征兆与替代**：缺背景补洞、前景边缘穿帮、深度方向错；用原片天然遮挡边界替代虚拟位移。
- **区别/机制**：三层差速 + 遮挡交接。原理依据见[来源P04](creative-sources.md#p04)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C15 亮度驱动的纹理溶接

- **场景与素材前提**：亮树叶、水面反光、云层能控制换场顺序；需亮暗结构而非纯白闪。
- **实现路径**：X：以亮度阈值递进生成alpha，让下一镜先从高光纹理透出再覆盖全幅；剪映缺可控亮度键时用本地遮罩序列预合成。
- **失败征兆与替代**：肤色先被挖穿、脏边、阈值跳级；只用无人空镜作过渡或改柔和叠化。
- **区别/机制**：亮度阈值动画 → alpha交接。原理依据见[来源P06](creative-sources.md#p06)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C16 撕纸前后景揭示

- **场景与素材前提**：日记、绘本、手工作为视觉概念；需有许可的透明撕纸边或自制纸纹。
- **实现路径**：M：纸面上放前一镜，下一镜在底层；撕口蒙版与纸边图同步走，适量阴影表达高度，手部在最前层。
- **失败征兆与替代**：纸边先走、内容后走、阴影方向乱；改一条直纸边，不叠随机纸屑。
- **区别/机制**：纸边/阴影/内容三层同步。原理依据见[来源P01](creative-sources.md#p01)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C17 弹性拉伸穿越

- **场景与素材前提**：玩具弹跳、橡皮筋或柔软材质有形变动机；需主体不被无意义拉坏。
- **实现路径**：X：围绕局部接触点对背景做短暂网格/位移畸变，最大形变时接下一镜再回弹；没有位移能力就用整幅缩放模拟并如实记录。
- **失败征兆与替代**：头像变形、主体拉长、色边过强；局限在不含人的背景区域，或改轻微压缩回弹。
- **区别/机制**：局部位移 → 峰值切换 → 回弹。原理依据见[来源P06](creative-sources.md#p06)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C18 物件逐帧替换转场

- **场景与素材前提**：玩具、食物、衣物可作为地点/时间标记；需锁定机位或能对齐的同构图。
- **实现路径**：M：挑若干清楚状态，以离散静帧逐格替换物件/背景，保持桌面或手的支点固定，最后一格恢复连续视频。
- **失败征兆与替代**：物件尺寸乱跳、每格全画面晃、闪烁过密；减少状态，只保留一次替换。
- **区别/机制**：离散状态替换 → 连续运动。原理依据见[来源P05](creative-sources.md#p05)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C19 网格多米诺接管

- **场景与素材前提**：同一事件有数个角度或动作阶段；需明确主格和统一方向。
- **实现路径**：M：把两场都分割成相同网格，让小格按行或对角顺序替换；每格错开起点，最后整体恢复一个画面，不让格子永远分散。
- **失败征兆与替代**：像随机幻灯片、人物面孔被切断、移动方向互撞；减少格数、避开脸部切线。
- **区别/机制**：同网格错时切换。原理依据见[来源P01](creative-sources.md#p01)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C20 多次遮挡拼成伪一镜到底

- **场景与素材前提**：需要连续跟随探索且路线上有树干、墙角或近物遮挡；各段运动方向、相机高度、光线要可接。
- **实现路径**：M：每次完全遮挡时接下一段，用关键帧补少量构图差并保留环境声连续；长段内部保留速度变化和视线引导，不宣称真实连续拍摄。
- **失败征兆与替代**：脚步节奏断裂、地理关系不可能、遮挡没满仍切；保留明确章节切点而非硬藏。
- **区别/机制**：多处隐藏切点 + 路线连续性。原理依据见[来源P03](creative-sources.md#p03)；具体组合为本工作流的编辑设计，非原教程逐步转录。
