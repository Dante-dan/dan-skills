# 定格、时间切片与停格动画

本页是[50项创意配方](creative-50.md)的一部分。路径M=剪映轨道/蒙版/关键帧手工组合，U=须核对本机实际UI，X=可能需要本地辅助预合成；均不代表已实机跑通。先读[执行与来源边界](creative-50.md#使用方式)，再只加载本次需要的条目。

<a id="c21"></a>

## C21 动作轨迹残影阵列

- **场景与素材前提**：跳跃、奔跑、挥手轨迹值得被看见；需清楚轮廓和足够连续帧。
- **实现路径**：M：从已遮挡合成抽取数个关键姿势抠像，按原轨迹留在画面里；当前人物继续移动，旧姿势按顺序退出，不把所有姿势堆到同一点。
- **失败征兆与替代**：重叠遮住主动作、发丝抠边、任一残影裸脸；减少样本并为每个副本保留头像。
- **区别/机制**：多时刻定格前景 + 活主体。原理依据见[来源P07](creative-sources.md#p07)；具体组合为本工作流的编辑设计，非原教程逐步转录。

- **补充原理/灵感**：[Y06](creative-sources.md#y06)，证据等级与未观看边界见来源页。

## C22 世界暂停而主角继续

- **场景与素材前提**：想强调主角沉浸在自己世界；需稳定背景底帧及可连续分离的主体。
- **实现路径**：M：底层冻结在同一瞬间，上层主角视频继续，环境声可渐收但脚步有选择地保留；结束时用对应帧恢复背景。
- **失败征兆与替代**：阴影停住而身体移动不可信、其他人切半、现场时间被误解；只在明显创意段使用，或冻无人背景。
- **区别/机制**：冻结背景 + 连续主体。原理依据见[来源P04](creative-sources.md#p04)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C23 绕着冻结瞬间移动

- **场景与素材前提**：关键动作后给观众看细节；需高分辨率定格与可分前中后层。
- **实现路径**：M/X：把主体、近景和远景拆层作小幅相反位移，模拟绕行；缺真实多机位时限制幅度，不称真实子弹时间或生成看不见的背面。
- **失败征兆与替代**：身体背面凭空出现、背景洞、头像脱层；改平面推近并保留原角度。
- **区别/机制**：单时刻2.5D视差。原理依据见[来源P04](creative-sources.md#p04)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C24 频闪曝光式动作分解

- **场景与素材前提**：需要展示球的飞行、手的运动或重复动作；需固定参照与间隔清楚的状态。
- **实现路径**：M：底图保留一帧，按等间隔抽取运动物体局部，依次亮起/消失；用编号或路径解释时间方向，与C21人物残影的连续留存分开设计。
- **失败征兆与替代**：轨迹互相遮住、速度关系被误画、过亮频闪；缩减为三阶段静态轨迹，不连续闪白。
- **区别/机制**：定时间隔采样 + 顺序点亮。原理依据见[来源P05](creative-sources.md#p05)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C25 抽帧节拍停格

- **场景与素材前提**：手作、玩具摆放或穿搭有清楚离散动作；需足够状态且能接受刻意停顿。
- **实现路径**：M：用短持有帧或离散静帧降低运动更新频率，输出仍保持项目59.94/60时基；动作只在选定拍位变，不把低更新率称低帧导出。
- **失败征兆与替代**：像解码卡顿、表情被截断、音频随静帧重复；仅放在物件段并保留连续环境声。
- **区别/机制**：低运动采样率 + 高输出时基。原理依据见[来源P05](creative-sources.md#p05)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C26 横条或竖条错时定格

- **场景与素材前提**：想把动作变成时间雕塑；需稳定横向或纵向经过的主体。
- **实现路径**：M/X：复制片段裁为少量条带，每条定在略不同的时刻，逐条恢复运动；若用逐像素时差才归C12，本条是清楚可读的分区时间拼贴。
- **失败征兆与替代**：脸/手被切成不适形状、条带接缝呼吸；只切背景或物件，主角保持完整前景。
- **区别/机制**：分区不同冻结时刻。原理依据见[来源P01](creative-sources.md#p01)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C27 定格停顿后追赶真实时间

- **场景与素材前提**：某个瞬间需要短暂停住观察，但音乐和事件仍继续；需暂停后留有非关键可压缩过程。
- **实现路径**：M/U：在源时间映射中插入短保持段，恢复后把非关键动作略加速，回到原定段落边界；原声与画面分开安排，台词不为追拍被任意压缩。无可靠曲线变速就分段恒速并复检。
- **失败征兆与替代**：接触动作被跳过、回接同帧产生重复动作、变速期间头像落后；缩短保持或放弃追赶，给事件完整时间。
- **区别/机制**：源时间保持 → 有界加速 → 回归实时。原理依据见[来源P03](creative-sources.md#p03)；具体组合为本工作流的编辑设计，非原教程逐步转录。

- **补充原理/灵感**：[G06](creative-sources.md#g06)，证据等级与未观看边界见来源页。

## C28 定格书页逐页翻成运动

- **场景与素材前提**：绘本/记忆主题需要从照片回到实拍；需动作起中末至少三张清楚定格。
- **实现路径**：M：先用少量独立卡片依次覆盖，卡片时间顺序形成翻页动画，最后一张匹配连续视频起帧接回；不只是加一个相框。
- **失败征兆与替代**：倒序不明、最后一张与活画面错位、翻页露出未遮挡底片；退成按序三张照片接实拍。
- **区别/机制**：多张时间采样卡 → 同帧恢复。原理依据见[来源P05](creative-sources.md#p05)；具体组合为本工作流的编辑设计，非原教程逐步转录。
