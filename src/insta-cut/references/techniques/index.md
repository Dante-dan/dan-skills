# 按叙事目的选择技法

先判断观众此刻需要看懂什么、感到什么，再选技法。这里是工具箱，不是每片必须集齐的效果清单。每个方案先做短样片，比较无效果版；表达没有更清楚就撤掉。参数是起点，随动作、画幅、时基和音乐调整。

## 工具和验证边界

剪映专业版是主时间轴和交付工具；本机实际功能、素材许可和会员可用性优先于网页宣传。CapCut 官方资料仅帮助理解技法，**不证明国内剪映某版本、JyWrapper 或草稿格式已经支持对应功能**。先检查已安装 jianying-editor 的真实 API、剪映 UI 和短片导出；没有验证的字段/资源 ID 不写入工程。

能在剪映用轨道、关键帧、蒙版完成的先用剪映。复杂路径文字、精确字形遮罩或局部混音确有必要时，可使用已安装且可用的辅助软件/FFmpeg 预合成，再导回剪映；没有软件不承诺该方案。保留可编辑来源、透明通道/编码信息和帧率，不使用 HyperFrames。

每个拟用技法在分镜中记录：`目的 → 源镜头/声音 → 技法ID → 前提 → 时间范围 → 实现路径 → 成人头像影响 → 无效果替代 → 复检结果`。先把成人 3D 动物遮挡与画面一起当作受保护合成：重新取景、变速、定格、转场、文字镂空都要检查是否出现裸脸或头像延迟。孩子的眼神和关键动作优先于装饰。

## 风格选择不是效果套餐

- **Ins 日记**：可用一套文字层级、少量运动标题和照片式段落；保留真实生活声，不把每句心情都写满屏。
- **蒙太奇**：围绕同一主题或动作发展，镜头尺度、方向、声音形成递进；不等于所有镜头等长卡点。
- **纪实短篇**：由人物行动、停顿和现场声音推进；技巧主要解决信息与连续性，关键情绪允许完整停留。
