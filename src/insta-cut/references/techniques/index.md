# 按叙事目的选择技法

默认创意第一、叙事第二，同时兼顾两者：主动提出统一视觉概念与大胆技巧组合，再判断观众此刻需要看懂什么、感到什么。这里是工具箱，不是每片必须集齐的效果清单。按项目brief的 `style_intensity` 选择密度：克制/平衡/炫技；默认创意强度高，用户明确要求纪实/克制时调整。每个方案先做短样片，比较无效果版；叙事、节奏或预定视觉趣味都没有提升就撤掉。参数是起点，随动作、画幅、时基和音乐调整，隐私、事实及可读性不因创意优先降低。

## 工具和验证边界

剪映专业版是主时间轴和交付工具；本机实际功能、素材许可和会员可用性优先于网页宣传。CapCut 官方资料仅帮助理解技法，**不证明国内剪映某版本、JyWrapper 或草稿格式已经支持对应功能**。先检查已安装 jianying-editor 的真实 API、剪映 UI 和短片导出；没有验证的字段/资源 ID 不写入工程。

能在剪映用轨道、关键帧、蒙版完成的先用剪映。复杂路径文字、精确字形遮罩或局部混音确有必要时，可使用已安装且可用的辅助软件/FFmpeg 预合成，再导回剪映；没有软件不承诺该方案。保留可编辑来源、透明通道/编码信息和帧率，不使用 HyperFrames。

每个拟用技法在分镜中记录：`目的 → 源镜头/声音 → 技法ID → 前提 → 时间范围 → 实现路径 → 成人头像影响 → 无效果替代 → 复检结果`。先把成人 3D 动物遮挡与画面一起当作受保护合成：重新取景、变速、定格、转场、文字镂空都要检查是否出现裸脸或头像延迟。孩子的眼神和关键动作优先于装饰。

## 风格选择不是效果套餐

每条故事先辨认它独有的动作、物件、空间或关系，再建立相应的视觉语法。例如小手触镜可驱动遮挡转场，玩偶互动可用漫画格表现视线和反应，夜间相遇可围绕灯光与人物距离组织画面；这些只是选法示例，不能轮流套用。新片与上条至少比较一次：技巧为何适合这次内容、哪处承担视觉高潮、哪处让动作完整展开。

“炫得高级”的审片判断：主次清楚，文字和装饰不争抢关键动作；字体、色彩、运动方向及加减速相互协调；转场有动作或构图承接，音效有对应事件；疏密与停顿让重点可感知。统一不等于每场相同，变化要有递进。发现效果抢走注意力、动势互撞、贴纸和转场各说各话，或移除后片子更好读时，先重做设计或删减该效果，再考虑加新效果。保持创意强度，以完成度而非堆叠取胜。

- **炫技/创意版**：用一个视觉概念贯穿，例如“孩子的小小世界”以定格抠像介绍、字层穿插、分屏动作呼应、速度变化和透视卡片展开；围绕真实动作安排起承转合，允许视觉奇趣本身成为观看价值。用一致的色彩、字体和运动方向组织密集设计，成人动物遮挡作为受保护前景，不因合成增加而泄漏；不是每条温馨片都需要此强度。
- **Ins 日记**：可用一套文字层级、少量运动标题和照片式段落；保留真实生活声，不把每句心情都写满屏。
- **蒙太奇**：围绕同一主题或动作发展，镜头尺度、方向、声音形成递进；不等于所有镜头等长卡点。
- **纪实短篇**：由人物行动、停顿和现场声音推进；技巧主要解决信息与连续性，关键情绪允许完整停留。
