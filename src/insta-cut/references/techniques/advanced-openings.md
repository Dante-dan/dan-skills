# 开场与视觉悬念

本页是[50项创意配方](creative-50.md)的一部分。路径M=剪映轨道/蒙版/关键帧手工组合，U=须核对本机实际UI，X=可能需要本地辅助预合成；均不代表已实机跑通。先读[执行与来源边界](creative-50.md#使用方式)，再只加载本次需要的条目。

<a id="c01"></a>

## C01 接触印样选片开场

- **场景与素材前提**：一组探索片段需要快速建立“今天看什么”；准备同画幅、已遮挡的4–9段短镜头。
- **实现路径**：M：把短片排成接触印样网格，先让一格播放、其余停住；用边框或游标选中主格，再让该格扩展为全屏并接连续动作。别只把同一镜头复制九份。
- **失败征兆与替代**：主格扩展时构图跳变、所有格抢眼、成人在小格漏脸；退为三格选片，仍保留“挑中一段”的动作。
- **区别/机制**：多轨/定格/网格 → 单格接管。原理依据见[来源P01](creative-sources.md#p01)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C02 逆向组装事件开场

- **场景与素材前提**：收拾玩具、撒落树叶等有清楚起终点的动作；需前后余量和可分离的原声。
- **实现路径**：M：从完成态开始，把短动作倒放到起点，停一拍，再接真实顺序；声音单独铺实际环境声，倒放段只用有意设计的回卷声。
- **失败征兆与替代**：物理过程被当真实事件、倒放说话或无意义回卷；用明确倒带视觉提示，或仅倒放无人物的物件。
- **区别/机制**：倒放 → 起点停顿 → 正向展开。原理依据见[来源P03](creative-sources.md#p03)；具体组合为本工作流的编辑设计，非原教程逐步转录。

<a id="c03"></a>

## C03 局部先醒来的动态照片

- **场景与素材前提**：想先让观众寻找画面里微小变化；需稳定机位、循环叶片/水面/衣角和静态底帧。
- **实现路径**：M：定格底层，上层视频仅通过局部蒙版显露运动；先形成动态照片，再扩大蒙版让全画面恢复活动，接真实时间。
- **失败征兆与替代**：接缝呼吸、背景整体抖动、循环末尾跳帧；换稳定空镜或缩小动态区域。
- **区别/机制**：静帧底图 + 局部活画面 → 全景启动。原理依据见[来源P05](creative-sources.md#p05)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C04 小行星展开成孩子视角

- **场景与素材前提**：全景素材有空间趣味，需要从世界建立进入人物；须有已拼接360球面源。
- **实现路径**：X：先在Studio核验投影/FOV是否可动画；不支持时用已有本地工具预合成小行星与正常投影连接，再进剪映接低机位主体；动物头像与投影一起处理。
- **失败征兆与替代**：接缝拉裂、地平线骤翻、放大后糊、头像仅在一种投影覆盖；退为固定小行星短卡接普通视角，不称相机实际飞行。
- **区别/机制**：球面投影变换 → 平面主视角。原理依据见[来源P01](creative-sources.md#p01)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C05 路线地图落点开场

- **场景与素材前提**：多地点行程需要把目的地讲清；准备有使用许可的简化地图或自绘示意图及真实地点关系。
- **实现路径**：M：路线拆成可逐段出现的线条/点，沿路径推进位置关键帧；抵达落点时放大一张实拍小卡，让小卡接管为下一镜。
- **失败征兆与替代**：地图地点不实、路径转角弹跳、个人精确位置被无意公开；改用不含地址的示意路线与地点类别。
- **区别/机制**：路径揭示 → 位置标记 → 实拍接管。原理依据见[来源P02](creative-sources.md#p02)；具体组合为本工作流的编辑设计，非原教程逐步转录。

<a id="c06"></a>

## C06 前景拉焦揭示开场

- **场景与素材前提**：前景花草或物件能制造悬念，后方人物是焦点；优先真实拉焦或两层能可靠分离的画面。
- **实现路径**：M：先给环境局部特写，焦点/局部模糊由前景移到主体，文字随清晰区域出现；后期用两层蒙版模拟时只称拉焦模拟，不把整屏模糊当镜头景深。
- **失败征兆与替代**：抠像边缘发亮、主体像贴纸、视线不知往哪；直接用真实前景特写切主体中景。
- **区别/机制**：前后景清晰度交接。原理依据见[来源P04](creative-sources.md#p04)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C07 画面内按钮启动故事

- **场景与素材前提**：孩子按玩具按钮、触镜或开盒有明确触发动作；准备自绘简洁界面与准确接触帧。
- **实现路径**：M：把播放/录制图形贴在真实交互位置，触碰帧做一次压缩与回弹；由这个动作启动画面、音乐或标题，而不是先播再补一个无关图标。
- **失败征兆与替代**：图形滑走、动作没碰到就触发、界面冒充真实设备记录；用明确插画风，或只保留接触动作转场。
- **区别/机制**：触碰事件 → UI反馈 → 开始播放。原理依据见[来源P02](creative-sources.md#p02)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C08 首尾回环的无缝开场

- **场景与素材前提**：想让短片结尾自然接回第一镜；需首尾物件、动作方向或构图可真实匹配。
- **实现路径**：M：先成对挑选首尾而不是剪完才找结尾；把结尾停在动作接续点，第一镜从对应动作阶段开始，单独处理原声尾与开头的接缝。可在第二遍观看揭示开场细节。
- **失败征兆与替代**：只靠倒放循环、动作方向反跳、音频接缝爆点或因果被改写；保留明确收尾，不强行闭环。
- **区别/机制**：首尾动作相位匹配 + 音频接缝设计。原理依据见[来源P03](creative-sources.md#p03)；具体组合为本工作流的编辑设计，非原教程逐步转录。
