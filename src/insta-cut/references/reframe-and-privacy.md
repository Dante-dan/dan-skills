# INSV 取景和纯动物头像

以下为 2026-10-19 本机实测，不是所有 Insta360 相机通用规格。先 probe、看连续画面再套用。

## 取景

该批 INSV 两路 1920×1920 鱼眼、120000/1001 fps 和原声音轨。优先 Studio 拼接、FlowState、重构后导出；两个相机方向可形成孩子近景与父母跟随视角，保持空间、时间关系。

Studio 无法导出时可 FFmpeg v360 直接取单鱼眼平面视角，不等于完整360拼接，也不提供 Studio FlowState。该批常需 hflip,vflip 才正向，不对新相机盲用。低成本测试双镜头、方向、俯仰、FOV，观察运动连续性。

本批竖屏示例，需按实际镜头替换角度与 FOV：

```text
fps=60000/1001,hflip,vflip,
v360=input=fisheye:output=flat:ih_fov=200:iv_fov=200:
h_fov=100:v_fov=129.5:yaw=0:pitch=0:reset_rot=1:w=1080:h=1920:interp=lanczos,
hqdn3d=1:1:2.5:2.5,scale=2160:3840:flags=lanczos,setsar=1
```

vFOV = 2*atan(tan(hFOV/2)*height/width)，注意弧度换算，不按宽高比线性放大。横屏可先测试1920×1080、hFOV约112、向上pitch约25，再输出3840×2160。去畸变后升采样必须披露，避免过量放大。M4 Max可用 hevc_videotoolbox 做中间片、H.264 MP4 交付，先确认具体工具支持。

核对独立音轨映射 `-map 0:a:0?`；实时节奏应正确丢帧到59.94并维持原声长度，不误将120fps直接解释成60fps慢动作。

## 动物资产与坐标

assets 内三张透明 PNG 是已生成的纯动物头部，可直接复制进项目。先确认 alpha 和脸部区域；图片中心不等于口鼻中心。

| 动物 | 动物脸部锚点（图片归一化） | 起始尺寸经验 |
|---|---|---|
| 熊猫 | (0.50,0.55) | 边长取成人脸高1.95倍或宽2.15倍中足够覆盖者 |
| 狐狸 | (0.49,0.62) | 边长约脸高2.25倍或宽2.3倍 |
| 兔子 | (0.50,0.74) | 长耳图边长约脸高2.95倍 |

仅适配所附资产，不保证新头像通用。验收标准是真实成人脸持续完整遮住，不是参数达到某值。

YuNet 可检测候选，CSRT/光流辅助跟踪，人工确认成人种子并双向跟踪、补关键帧；切镜头重置轨迹。儿童不遮，建筑/海报误检不贴。夜景与画面边缘侧脸易漏检，必须看真实图像。

成人在孩子后面时，前景蒙版限定于孩子真实轮廓；过大椭圆可能还原成人脸。头像前后关系和儿童眼睛、手、头发附近逐帧看。成人进出画、快转、运动模糊加余量，跟不稳就裁掉或弃片。

## 可恢复的小体积工程

联系表用带时间码低分辨率，不预先导出整批4K中间片。按选中区段高质量重构，估算工作空间后渲染。空间不足不删未核验归档源片。

保存源时间码 EDL、取景参数、头像轨迹、资产和工程依赖，确保能由 Drive 原片重建。检查最终MP4真实播放而非只看工程预览。实际时间轴与导出使用剪映，不使用HyperFrames。

实际剪映操作时再读 [本机兼容性与实测](jianying-compatibility.md)，避免把历史UI行为与参数当通用规格。
