# 音轨与画面节奏的本地复核

当需要判断切点、动作疏密与音乐是否呼应时读取。本地信号分析补充审片证据；它不让只接受图像/文本的agent突然获得听音能力。完整声音理解需要实际支持音频输入的模型或人工监听，不能把ASR文字、频段能量或BPM当作实际听完。

## 可运行路径

使用技能内 [analyze_av_rhythm.py](../scripts/analyze_av_rhythm.py)。在项目工作目录创建隔离环境，安装 `librosa==0.11.0`、`numpy`、`scipy`、`matplotlib`，系统需有FFmpeg。不要为一个分析器修改系统Python；依赖网络失败时有界退出并说明，不无限重试。脚本全部本地运行，不上传片子或调用API。

```bash
python <skill>/scripts/analyze_av_rhythm.py \
  --video <当前待审预览.mp4> --music <实际配乐文件> \
  --plan <当前时间轴.json> --output <项目work/audio-review>
```

计划文件包含 `duration` 与 `shots`，每镜有 `start`、`duration`，可有 `reason`；时间须与当前预览相同。配乐有起始偏移时传 `--music-offset`。当前辅助工具只分析**一条连续配乐**，换曲/变速/循环的配乐需先从时间轴导出对应连续参考stem并核对时间，不能把源曲直接当当前配乐。可传 `--original-audio`，应为已按实际增益、淡化和延迟合成的原声bus，不能拿不同音量原片作遮蔽比较。

产出 `rhythm.json` 和 `rhythm-overview.png`：当前文件/计划/配乐指纹、估计拍点及音符起音、精确计划剪点到候选拍点/起音的**有符号**偏移、混音与原声RMS、画面活动代理及时间轴。正偏移表示音乐事件在剪点之后；负偏移表示音乐先到。画面变化在剪点附近剔除，以减少切镜本身造成的活动尖峰。输出只能是 `analysis_only`，不能自动签独立通过。

## 如何据此作编辑决定

- **先看镜头动机**：亲子对视、摸索与牵手允许跨拍停留；探索蒙太奇可让关键行动或段落变化靠近音符起音。偏移大仅列复查，不自动吸附切点。镜头起止按实际计划，不用低帧率场景检测替代精确剪点。
- **音乐与原声分开**：从独立配乐找拍，最终混音检查电平变化；脚步、童声或风噪不能冒充音乐重拍。原声bus/RMS只能筛查风险，不能证明对白清楚；ducking后配乐要看真实时间轴包络或实际stem。
- **看局部与全片疏密**：对照画面活动、镜头时长与音乐能量，列具体时间码、预期作用和可选修法。音乐起音不是乐句边界；拍点拟合很规整也不证明节拍可信。疏朗钢琴尤其要避免被算法默认节奏带走。
- **保留主观与技术边界**：不能由卡拍比例、某个LUFS、频段声压或画面差分自动推出“电影感”“专业级”“笑声”“情绪一致”。单声道过采样峰值仅作筛查；正式编码仍查左右声道真峰值、单声道兼容、音画同步和实际声音。
- **修法尽量小**：关键段落可尝试移动配乐起点、保留尾音/环境声桥或调整少数剪点，记录原声同步和叙事影响；不要为卡点截断孩子表情。先导待审预览，独立复检后再认定成片。

## 找到的技能与能力边界

[reel-audio-sync](https://github.com/ndpvt-web/reel-analyzer/tree/master/reel-audio-sync)提供节拍/声音事件/切点对照思路，但其中的固定卡拍比例评级、默认拍号和频段事件语义不作为本技能验收依据。其总流程有远程AI综合步骤与系统依赖安装；不用它的总入口处理家庭片。未核实可再分发许可时只链接研究，不复制第三方源码进本仓库。

[Qwen MM Plugins](https://github.com/QwenLM/Qwen-MM-Plugins)提供实际音频/声画模型工具的接入路线。必须先核实当前有可用的音频模型后端；skill说明不等于已配置。家庭视频/原声传到新的外部模型服务前，需明确用户对该素材与目的地的授权；优先已配置且可用的本地服务。未接通不阻塞已有本地专项检查，也不伪称完成听音。

算法依据：[librosa beat tracker](https://librosa.org/doc/0.11.0/generated/librosa.beat.beat_track.html)、[onset detection](https://librosa.org/doc/0.11.0/generated/librosa.onset.onset_detect.html)。来源核验：2026-10-20。
