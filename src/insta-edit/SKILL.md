# Insta Edit：创意剪辑

默认**创意第一、叙事第二，同时兼顾两者**，主动设计统一视觉概念，按实际内容选择技巧。用户要求纪实或克制时调整强度；隐私、事实、可读性和源质量限制始终保留。可独立处理普通视频，也可接收 [insta360-select](../insta360-select/SKILL.md) 的镜头包；完整归档/确认后清理由 [insta-cut](../insta-cut/SKILL.md) 编排。

## 接手素材

读项目状态、当前用户反馈及 `selection.json`（若有），按 [交接约定](../insta-cut/references/handoff.md) 核实源时间码、可读文件、精确时基和最高质量来源。已有素材可直接剪，不强制去Studio；清单存在也要实际看镜头及相邻片段。需要补镜时明确返回缺哪个动作/景别/区段，不重复选全批。缺少最高质量源时可做标明限制的预览，不以代理放大冒充最高画质成片。

按制作日组织草稿/素材/工作视频/预览及 `YYYY-MM-DD cuts/`，真实剪映draft留应用管理位置并记录索引。创意脚本写在用户项目内，不写进skill。详细流程和日期组织见 [制作流程](references/production-workflow.md)。

## 创意、画面与声音

1. 先写简明brief：故事/视觉概念、观众、画幅、`style_intensity`（克制/平衡/炫技；默认高创意强度）、视觉语法、镜头与声音走向、成人风险。用真实素材寻找人物行动与变化，编排可执行源时间码分镜；不同版本应有不同内容/故事或视觉概念，不靠同镜头换音乐充数。
2. 先原片空镜、反应和动作细节，再按 [素材来源](references/material-sourcing.md) 补B-roll/图像/声音。Openverse、Freesound等按实际作品许可记录，外部地点不能冒充当次经历，不为素材数量硬塞挂件。
3. 进入 [技巧索引](references/techniques/index.md) 按镜头读取：需要开场、空间/时间转场、定格、关键帧、正片叠加、画中画或自动卡点时查 [50项配方](references/techniques/creative-50.md)；组合难度参考 [镂空字/轨迹放大/多重九宫格 H01–H04](references/techniques/opening-combinations.md) 和 [R01–R12复合配方](references/techniques/compound-recipes.md)。从内容选主机制，用构图、运动和声音统一；不把上一条分屏/圆窗复用成固定模板，不以特效数量衡量创意。纸面配方不等于本机已复现，先做最难片段短样片。
4. 用当前安装的 `jianying-editor` 技能搭建剪映时间轴并原生导出；先读它的SKILL.md并核实本机能力。不使用HyperFrames。FFmpeg等只辅助取景、蒙版、预合成、混音或检查，真实记录分工，不把烘焙画面说成全部原生可编辑。实机问题再读 [剪映兼容性](references/jianying-compatibility.md)。
5. 成人全部用一致、可爱的**纯动物3D头部**覆盖，儿童真实；复用本skill `assets/animal-{panda,fox,rabbit}.png`，缺资产可用可用的imagegen技能生成，不上传家庭人像换动物。按 [头像与儿童保护](references/adult-privacy.md) 检查背景成人、边缘、旋转、遮挡及跨镜头轨迹。前期选镜风险清单不代替最终帧检查。
6. 花字/文字模板、字体、贴纸和会员特效围绕主题及动作设计；文字可镂空、跟踪、遮挡、与画面互动，不直接沿用系统字体，不以静态字幕条替代全部表达。装饰出场顺序有逻辑，不能挡住孩子或关键动作。保留自然肤色和现场声音，音乐给笑声/脚步/对白留空间。
7. 音乐、音效与剪点按节拍、乐句、呼吸共同编排；用J/L cut、环境声桥、ducking、淡化、混响尾音及静默衔接，避免无动机硬切。按需读 [本地节奏复核](references/audio-rhythm-analysis.md)，波形/拍点不能冒充听音或全片审阅。

## 预览、独立审片和最高画质导出

可先剪映原生导出完整待审预览，带实际混音、明确版本且放工作目录，未通过不能称合格成片。按 [独立审片](references/independent-review.md) 让未参与制作的agent先预检完整看/听和必要逐帧能力；缺必需能力立即记录 `independent_review_pending` 及真实缺项，结束本轮，不循环等待或将技术检查补作全片通过。可按需委派素材、视觉或声音方案，只有一个主剪写时间轴；最终审片人独立于作者。

独立审当前实际声画和高风险帧，修复后绑定新时间轴版本/编码重审。用户单轮豁免只记当前故事/版本及准确维度，不扩为全局免听音。独立通过与用户确认是两回事，不能代替彼此。

正式交付普通平面视频，横竖由故事决定；按当前剪映实际支持的最高画质、4K和准确约60帧时基导出。59.94用 `60000/1001`、真60用 `60`，保持高质量来源及足够高码率，减少有损重编码，不写死100/200Mbps，也不把升采样称原生细节。细节见 [最高画质交付](references/production-workflow.md#最高画质交付与代理分离)。实际检查全片解码、规格、头像、字边、快运动、头尾、同步和声音；如另作高质量编码，须对照已审版本完成回归。已审同一编码达到交付规格可直接晋级，不为改文件名重复导出。

输出 `edit-result.json`及当前可播放文件、draft/源依赖索引、许可和真实QC/审片结论，见 [交接字段](../insta-cut/references/handoff.md)。仅在必需审阅及检查通过后标 `final_verified`；否则交付待审预览和缺项，不假称成片。此skill不因剪辑完成就删除原片或发布平台：整轮由insta-cut做私有归档、唯一文件名核对及用户确认；独立调用时未另授权的云上传/发布/清理只记后续交接。已明确授权的平台交接可按 [剪映交接](references/jianying-compatibility.md#有限时长输出与交接) 执行对应范围，不越过上传与最终公开边界。
