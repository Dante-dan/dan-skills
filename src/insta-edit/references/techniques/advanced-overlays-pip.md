# 正片叠加、合成与画中画

本页是[50项创意配方](creative-50.md)的一部分。路径M=剪映轨道/蒙版/关键帧手工组合，U=须核对本机实际UI，X=可能需要本地辅助预合成；均不代表已实机跑通。先读[执行与来源边界](creative-50.md#使用方式)，再只加载本次需要的条目。

“正片叠加”在本页指在主画面上合成其他图层。选混合方式时明确参数名称，分别检查黑位、白位、肤色和alpha边缘；不要把叠一条轨道自动称为使用某种混合模式。

| 方式 | 常见素材/用途 | 本机小样重点 |
|---|---|---|
| Normal + alpha/蒙版 | 透明贴纸、人物、视频小窗 | 透明边缘与前后遮挡，半透明处是否漏出成人原脸 |
| Multiply / 正片叠底 | 白底纸纹、线稿、压暗纹理 | 白底是否近似中性、暗部是否被压脏 |
| Screen / 滤色 | 黑底光迹、火花、亮部纹理 | 黑底是否消去、高光是否过曝；对应C38 |
| Overlay / 叠加 | 需要增强明暗对比的纹理 | 中灰附近与肤色是否保持可接受，不能当无损透明化 |

混合原理参考[FFmpeg官方blend](https://ffmpeg.org/ffmpeg-filters.html#blend_002c-tblend)；剪映实际色彩处理、可选模式和预览结果须另验。没有合适模式时换透明素材或本地预合成。

## C37 人物轮廓双重曝光

- **场景与素材前提**：需要记忆/想象表达；准备清楚轮廓和有语义联系的空镜，明确是艺术合成。
- **实现路径**：M/X：用人物轮廓作遮罩，把空镜限制在轮廓内部；再用低强度原主体保留识别度，结尾恢复真实画面。成人仍用动物头像覆盖，不以合成代替隐私。
- **失败征兆与替代**：五官漏出、轮廓看不清、无关风景冒充经历；改物件轮廓或清楚分开的回忆小窗。
- **区别/机制**：轮廓alpha × 内部第二影像。原理依据见[来源P01](creative-sources.md#p01)；具体组合为本工作流的编辑设计，非原教程逐步转录。

- **补充原理/灵感**：[Y03](creative-sources.md#y03)，证据等级与未观看边界见来源页。

## C38 有黑位保护的Screen叠加

- **场景与素材前提**：火花、光斑、灰尘等要融入正片；需许可素材、黑底/alpha信息和足够高质量。
- **实现路径**：M：先比对Screen/Lighten/Normal-alpha的真实结果，控制高光/黑位和局部遮罩；叠加层跟随镜头而非随意漂，压低强度保留主体。
- **失败征兆与替代**：黑底没去掉、全片灰白、皮肤被光斑覆盖；换透明素材或仅局部叠加。
- **区别/机制**：混合模式 + 亮度/区域约束。原理依据见[来源P06](creative-sources.md#p06)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C39 前景遮挡与环境光包裹

- **场景与素材前提**：抠像人物或贴纸看起来悬浮；需场景光向、边缘遮罩与接触关系。
- **实现路径**：M/X：先让真实前景盖住合成物，再从环境色取非常窄的柔光边，补适量接触阴影；不以全身发光来掩盖差抠像。
- **失败征兆与替代**：边缘霓虹圈、阴影方向错、成人动物头alpha外漏；减小光包裹范围，重抠边或移除合成物。
- **区别/机制**：前景遮挡 + 光色/阴影融合。原理依据见[来源P04](creative-sources.md#p04)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C40 局部特效窗口叠在正片

- **场景与素材前提**：想强调正在摸的物件或观察范围；需一个有清楚目标的圆窗/手绘窗口。
- **实现路径**：M：保留正常正片，在上轨复制相同时间片，仅窗口内做放大、去色或细节处理；窗口位置跟目标走，出场后收回同一目标。
- **失败征兆与替代**：时间错一帧、窗口挡主动作、放大毫无细节；缩短持续时间或改静态箭头。
- **区别/机制**：同时间片 + 局部属性差异。原理依据见[来源P01](creative-sources.md#p01)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C41 延迟反应画中画

- **场景与素材前提**：一次动作和稍后反应有关，想让观众同时看见因果；需时间顺序可解释。
- **实现路径**：M：主画面先演动作，小窗稍后进入反应镜头，用短标签/明确剪辑语法说明回看或延迟；主音轨保持优先，不冒称同一时刻。
- **失败征兆与替代**：用错反应、同时播放语义混乱、两路原声互抢；改主片接反应的顺序剪。
- **区别/机制**：主事件 + 有意错时反应窗。原理依据见[来源P01](creative-sources.md#p01)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C42 Droste递归画中画

- **场景与素材前提**：镜子、相框或摄影主题需要“画面里还有画面”；需稳定内框与足够像素。
- **实现路径**：M/X：先做一层内嵌，再把已合成结果有限递归2–3层，各层缩放中心保持一致；预合成记录层数，禁止无限递归渲染。
- **失败征兆与替代**：深处变噪点、窗口位置漂移、晕动或重复成人漏脸；只保留一层屏内画面。
- **区别/机制**：有限递归嵌套；不是C10单次推入。原理依据见[来源P06](creative-sources.md#p06)；具体组合为本工作流的编辑设计，非原教程逐步转录。

- **补充原理/灵感**：[Y10](creative-sources.md#y10)，证据等级与未观看边界见来源页。

## C43 同一全景的虚拟多机位画中画

- **场景与素材前提**：想同时看到孩子行动与父母距离；需同一360时间源且各视角实际包含目标。
- **实现路径**：X/M：Studio从同一源时间分别导出主视角/反应视角，按准确时间码同步入剪映，小窗仅在需要空间关系时出现；每个取景分别做成人遮挡。
- **失败征兆与替代**：把不同时间伪装同步、两路声音梳状干涉、小窗太小、第二视角像素不足；只保留主视角加方向图。
- **区别/机制**：同一时间源不同投影 + 同步PiP。原理依据见[来源P01](creative-sources.md#p01)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C44 同景克隆互动合成

- **场景与素材前提**：同一空间出现数个主角版本用于明确的趣味段；需锁机、干净底图、独立表演或清楚时间采样。
- **实现路径**：M/X：不同表演放不同轨，蒙版分区；发生跨区重叠时逐帧做前后遮挡，统一阴影与尺度。标为创意合成，不声称实际有多个孩子。
- **失败征兆与替代**：人物互相切断、背景亮度跳、互动视线对不上；减少为两角色且不重叠。
- **区别/机制**：不同表演时间合成；区别C21轨迹静帧。原理依据见[来源P07](creative-sources.md#p07)；具体组合为本工作流的编辑设计，非原教程逐步转录。

- **补充原理/灵感**：[Y06](creative-sources.md#y06)、[Y07](creative-sources.md#y07)，证据等级与未观看边界见来源页。
