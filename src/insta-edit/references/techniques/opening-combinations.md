# 补充开场组合（H01–H04）

用户追加的四套开场配方，扩展[C01–C50](creative-50.md)，保留原有编号。按真实动作选用，不把四套自动串成一个片头；本次为设计配方，未在本机实际导出。需要字幕、蒙版、运动的基础时，分别读[T05/T07](typography-and-motion.md)、[C29/C30/C36](advanced-keyframes.md)和[叠加模式对照](advanced-overlays-pip.md)。H03/H04是[C01接触印样](advanced-openings.md#c01)的明确九宫格组合版本，不把底层网格工具重复算入原50项。

需要同等复杂度、适用于其他段落的组合时，转到 [R01–R12](compound-recipes.md)：除开场外，也有正片动作、视点接力、场景转换及收尾的设计，不重复四种开场当作新配方。

## 共同前提与图层约定

- 先看连续镜头，挑一个明确主动作：伸手、转身、跑动、抛物或打开物件。主标题是短故事主题，字体按粗细、字面大小与画面留白选择；实际核对字体/模板可用与许可。
- `V_safe(t)` 表示成人已用纯3D动物头像遮挡的高质量视频；任何复制、抠像、字孔内画面和最终全屏都从该版本取。儿童面部仍真实。主体前景若另作抠像，成人头像必须随同该前景一起抠出/合成。
- 分清三个对象：**透明字孔**是色块中的孔；**空心描边字**只有字形轮廓；**字内视频**用字形限制视频可见范围。根据画面选其中一种并记录，不把描边字冒充字孔。
- “正片叠加”先指主画面与其他层合成。Normal-alpha、Multiply、Screen、Overlay按素材和实际效果选择；不靠降低整组不透明度露出未遮挡原片。
- 开场时长随动作与停读需要调整，下面约3秒只作分镜起点；秒数换算到准确59.94/60项目帧边界。先在本机做最难边缘/运动短样片，再决定整段实现；剪映无可靠字形蒙版或轨迹描线时，用已安装本地工具做高质量预合成后导回，不写未经验证的草稿字段。

## H01 镂空字体＋正片叠加：字里看见，人物走到字前

**适用场景**：首次看见某个物件、进入新环境或一次清楚的人物登场。有可读大字、干净前景轮廓、字孔内仍可辨认的动作与足够留白；复杂发丝、快速遮挡或满屏人群先缩减设计。

### 图层顺序（由上到下）

| 层 | 内容 | 作用 |
|---|---|---|
| L4 | 已遮挡的主体前景＋同一主体动物头像 | 人物/手部局部越过文字边缘，建立前后关系；没有这个需要就不加 |
| L3 | 少量描边或辅助小标题 | 字形与背景接近时增强阅读；不占据主表情 |
| L2 | 带透明字孔的主题色板 | 字外有色板，字孔处露出下面的正片 |
| L1 | `V_safe(t)`连续正片 | 在字孔中实际运动，退出片头后继续同一镜头 |

上表采用“色板挖字孔”路线。另一种“字内视频”路线使用字形alpha约束视频，**字外须有独立底色、色板或可区分的背景**；不能在它下面同时直接显示完全相同的全幅同帧视频，否则字形层会看不出来。准备同源同帧全幅正片供最后交接，但先由独立背景遮住；退出时扩大字形可见范围并撤背景，或用匹配画面切到全幅。压暗背景只处理亮度，不降低成人动物遮挡的不透明度。

### 约3秒编排

| 名义时间 | 画面/动作 | 实现重点 |
|---|---|---|
| 0–0.6秒 | 先看见镂空大字中的运动，现场声音可提前进入 | 字孔取当前镜头，不随机塞另一段风景；标题先能读清 |
| 0.6–1.7秒 | 主体前景越过一部分字边，正片持续播放 | L4与L1使用完全相同源时间；前景不是静止贴纸，成人头像属于前景的一部分 |
| 1.7–2.5秒 | 字孔扩展或色板退出，让正片接管全屏 | 优先动画蒙版/色板而非把整组低清预合成放大；保留正片真实像素 |
| 2.5秒以后 | 留出完整动作和原声，继续正片 | 不再补第二次相同标题，退出所有无用辅助层 |

**具体实现选择**：剪映本机若能做稳定字形/反向蒙版，则叠轨实现；否则预制带正确alpha的4K字孔色板，导入后动画位置/缩放或切换预合成遮罩。黑白蒙版与透明PNG按实际输入方式核对，不能默认黑色会透明。若字孔需要变形/复杂跟踪，先明确本地辅助工具与导出格式，试样通过才用。

**质检与替代**：同一帧对照L1/L4，查重复轮廓、头像错位、字孔露脸、预乘alpha黑边、细笔画闪烁和标题停读时间。前景轮廓不稳就取消L4，保留字孔＋连续正片；字孔太碎就用空心描边字叠在真实画面上，并记录这是另一种视觉方案。声音只保留一条同源主音轨，避免复制视频时原声叠加。

**依据**：[Adobe字内视频](https://www.adobe.com/learn/after-effects/web/alpha-channel)、[Adobe轨道遮罩](https://helpx.adobe.com/after-effects/desktop/work-with-transparency-and-compositing/work-with-track-mattes-and-traveling-mattes/track-mattes-and-traveling-mattes.html)支持合成原理；[Y04](creative-sources.md#y04)仅为创作者公开描述的前景遮字灵感。以上节奏与层次是本工作流设计，不证明本机剪映存在同名一键效果。

## H02 关键帧＋轨迹动画＋放大＋正片叠加：沿线追到主角，窗口接管全屏

**适用场景**：小手伸向玩具、脚步开始奔跑、飞盘移动或镜头跟随探索。需可认知的起点、路径、落点，以及最终能承接连续动作的清楚正片。轨迹可用真实运动的简化线，也可用明确插画风的引导线；不把设计路径伪称真实追踪数据。

### 图层与运动分工

| 组 | 内容与关键帧 | 约束 |
|---|---|---|
| 背景组 | 全画幅`V_safe(t)`，可短暂压低明暗以托住包装 | 字与轨迹退出后恢复自然肤色，不持续模糊正片 |
| 路径组 | 线条逐段显露；小标记/标题沿线移动并适当转向 | 线条显露与标记前进要同步；不只移动一张完整线图冒充描线 |
| 窗口组 | 已遮挡的正片小窗，位置沿路径移动，落点后放大 | 视频、边框、必要阴影和动物头像保持同一变换；不要各自独立漂移 |
| 前景组（可选） | 真实手部/物件跨在路径或窗口之前 | 用遮挡建立接触关系；保持孩子眼神与关键动作无遮挡 |

### 约3秒编排

| 名义时间 | 画面/动作 | 实现重点 |
|---|---|---|
| 0–0.5秒 | 从真实动作位置生出一个小点/短线，窗口出现 | 接触帧或视线是启动信号，不能图形先飞完人才伸手 |
| 0.5–1.5秒 | 标记与小窗沿弧线推进，线条跟着显露 | 位置、旋转与描线进度联动；起步可缓，途中保持有目的的速度 |
| 1.5–2.3秒 | 到达目标，窗口适量超调后扩大接管画幅 | 放大围绕路径落点；进入全屏之前核对窗口裁切与目标全屏构图 |
| 2.3秒以后 | 撤掉边框/路径，接管为同一时刻的连续正片 | 以同源同帧交接避免跳动；声音继续主音轨，包装音效只点接触/落位 |

**剪映手工路径**：用位置关键帧确定弧线路点，必要时插入中间点；旋转按运动切线，缩放在到达后启动，先后分工清楚。关键帧曲线若本机可用再做缓入/缓出，不能所有属性同时归零又同时爆发。普通位置关键帧不等于蒙版形状动画；无原生描线功能时，用少量线段依次显露，或本地生成透明描线短片，保持与标记同进度。

**窗口放大两种实现**：若独立小窗源在最终构图下仍有真实分辨率余量，可整体做位置/缩放关键帧；若小窗预合成分辨率不足，保持底层4K正片不动，让上层边框/遮罩窗口扩展来揭示它，再按同源同帧切换。放大不恢复丢失细节。带源trim素材的关键帧先按[三时间坐标规则](../jianying-compatibility.md#关键帧与节拍自动化核验2026-10-21只读代码)验证，不默认使用时间轴绝对时间。

**质检与替代**：查路径尖角急刹、标记与线头不同步、窗口与真实手指滑脱、放大时像素化、全屏交接跳帧、子图成人漏脸、运动模糊吞掉主体与音效不对接触。弧线难以稳定完成就改直线两点路径；窗口放大不清就用全分辨率蒙版揭示；没有动作动机就取消路径，保留短标题与正片。

**依据**：[关键帧速度原理P02](creative-sources.md#p02)、[插值与错峰G07](creative-sources.md#g07)、[本机兼容性](../jianying-compatibility.md)、[混合/透明叠加P06](creative-sources.md#p06)。具体组合仍是编辑方案，真实执行须确认本机工具、最难动作样片与最终导出。

## H03 九宫格开场：分批亮起，主格放大接管

**适用场景**：同一天有多个动作/物件/环境细节，需要先交代丰富性，再带观众进入一个故事。准备九个明确可区分的画面单元，允许部分是定格或空镜，不用九段相同奔跑凑数；不强求九格都同时运动。

### 构图与图层

- 九宫格是**3行×3列**，不是9:16画幅。按最终横竖画幅等分，单元可为矩形；各格用裁切/留边适配，不能拉伸人物。无间距的3840×2160画布每格1280×720，2160×3840每格720×1280；加间距后重新计算，不强套这组尺寸。
- 每格使用独立`V_safe(t)`或已遮挡定格，保留同一套边框/间距。先在分镜给格子分工，如环境、主角、动作、反应、物件；按真正的关系安排相邻位置，避免任意填格。
- 始终指定一个主格，其他格以静帧、较弱对比或延后播放让位。各格原声默认静音，只留一条主视点环境/动作音轨；有必要切换主格声音时做有界衔接。

### 约3–4秒编排

| 阶段 | 动作 | 关键关系 |
|---|---|---|
| 建立 | 先出现一个与开场事件有关的主格，其余格按行、对角或外圈顺序补齐 | 入场次序跟动作/音乐主拍走，同一批用相同运动方向；不九格同时弹跳 |
| 选中 | 九格稳定短暂停留，主格边框或亮度轻强调，其余格收静 | 观众先看懂主格，再放大；不每格都加标签 |
| 接管 | 主格从所在格位扩大到整屏，其余格退出或被遮住 | 用位置/缩放与蒙版控制，主格视频与动物头像同一变换 |
| 展开 | 边框退出，接主格相同源时间的连续正片 | 真实动作继续，不在接管帧重复或丢掉关键触碰 |

**清晰度路径**：九格概览可用高质量预合成减轻解码，但放大时用**主格独立的全分辨率原片合成**覆盖原格，并按同源同帧交接；不要把1280×720的格子像素直接拉成3840×2160再称最高画质。主格源细节不足则缩短/减小推近，转为明确硬切。记录格子裁切、选中格、源时间及目标时间，先验证最难的放大交接。

**质检与降级**：查九格构图重复、细脸不可读、成人缩略图漏脸、格子边缘缝隙、主格放大中心跳变、角落安全区、九路声音混乱，以及手机观看时能否认出主线。素材不够就用三格或四格，不为了九格造无关故事；性能不足时其他格用定格，仅主格播放。

**实现边界**：剪映多轨＋位置/缩放/裁切与短样片核验；不默认有“一键九宫格”模板或API。原理依据见[C01](advanced-openings.md#c01)、[多轨与关键帧G02](creative-sources.md#g02)、[错峰G07](creative-sources.md#g07)。

## H04 多重九宫格开场：选中一格，进入第二层世界

**适用场景**：有“多地点→某地点”“多活动→某次探索”这样的真实层级，希望用选择与深入建立悬念。先为外层九格定义类别，再给目标格准备内层内容，不能只是把同样九段不断缩小。

### 两种组织方式，按故事择一

1. **嵌套深入**：外层3×3建立当天活动；镜头推向一格，进入该格内部的新3×3；第二层再选一格接管正片。这是沿一个分支深入，不要求同时播放81路视频。
2. **多组接力**：第一组九宫格整体滑出，第二组沿同向滑入；通过同位置主格/同构图物件衔接。适合时间推进，不声称是空间上的无限嵌套。

### 嵌套版本约4–6秒编排

| 阶段 | 动作 | 控制重点 |
|---|---|---|
| 外层概览 | 外层九格分批入场，目标格先吸引注意 | 每层只设一个主格，按H03处理视觉/声音主次 |
| 第一层进入 | 放大到目标格，目标格内部的第二组九格逐步可读 | 内层只在达到可读尺度时启动运动；外层其他格停止或退出 |
| 内层选择 | 用方向线、轻边框或动作吸引到第二层主格 | 不重复全部入场动画，第二层节奏更简洁 |
| 第二层接管 | 第二层主格放大为高质量连续正片，网格全部退出 | 每次进入均独立调用对应全分辨率源，不连续放大低清总预合成 |

**工程分组**：外层网格、目标格里的内层网格、最终主镜头分别管理。先列出树形关系与各组源时间，再在剪映用可验证的分组/复合片段或已安装工具预合成；不假设父子变换、递归草稿、自动分组API可用。若本机没有可靠嵌套，则把两段网格分别做成有限长度高质量片段，用同构图交接；明确哪部分为预合成。

**渲染与可读性**：最多先设计两层；额外层必须有独立信息价值和样片证据。外层概览可停格，进入目标分支才激活内层；只需并行解码当前可见的少量活画面。给工程与渲染设有限时长/层数，不用递归引用自己的片段。9×9只是两层全部展开时的理论81格，不是此配方要求或能力承诺。

**头像与音画**：每一层、每个格子及被放大的独立源均从`V_safe(t)`取，不以“太小看不清”豁免成人遮挡。同源多个格子的音轨不叠放；随着视觉深入只保留当前主视点，环境声桥可连续，音效只对应一次层级进入。不同时间/地点并列要有明确日记/蒙太奇语法，不假装同时发生。

**质检与降级**：第二层像噪点、无限缩放眩晕、两层内容无关、每次都同样弹跳、接管时糊/跳帧、资源占用异常，就减少层数/活画面；保留单层H03或采用多组接力。主线不需要分类深入时，不用多重九宫格。

**依据**：[有限递归C42](advanced-overlays-pip.md#c42)、[C01](advanced-openings.md#c01)、[G02](creative-sources.md#g02)、[G07](creative-sources.md#g07)。两种组织是本工作流设计，未在本机实测81路或自动网格成片。
