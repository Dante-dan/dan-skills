# 关键帧与运动设计

本页是[50项创意配方](creative-50.md)的一部分。路径M=剪映轨道/蒙版/关键帧手工组合，U=须核对本机实际UI，X=可能需要本地辅助预合成；均不代表已实机跑通。先读[执行与来源边界](creative-50.md#使用方式)，再只加载本次需要的条目。

## C29 预备动作—过冲—回稳

- **场景与素材前提**：图形、标题或小窗要表现重量与弹性；需足够负空间和确定落点。
- **实现路径**：M：先略反向预动，再快速越过终点，最后小幅回到稳定位置；位置/缩放分别控制，结尾留可读停顿。无曲线编辑器时用分段关键帧。
- **失败征兆与替代**：无休止弹跳、文字还在晃就切走、动物头像被当弹性玩具暴露底脸；只动画包装组。
- **区别/机制**：anticipation → overshoot → settle。原理依据见[来源P02](creative-sources.md#p02)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C30 弧线路径与切线朝向

- **场景与素材前提**：飞盘、纸飞机图形或路线节点需要绕行；需可追踪路径和安全画外余量。
- **实现路径**：M：位置关键帧沿弧线布点，并按切线调整旋转；曲线不可用时分段拟合，检查速度，而非只看静态路点。
- **失败征兆与替代**：拐点急折、物体沿路反转、尾迹与头部脱节；减为两段圆弧或直线。
- **区别/机制**：空间路径 + 朝向联动。原理依据见[来源P02](creative-sources.md#p02)；具体组合为本工作流的编辑设计，非原教程逐步转录。

- **补充原理/灵感**：[G07](creative-sources.md#g07)，证据等级与未观看边界见来源页。

## C31 铰链轴翻开画面

- **场景与素材前提**：门、书本、窗户主题；需明确支点与背面设计。
- **实现路径**：M/X：把支点设在一条边或预合成画幅边，再绕该边翻转；剪映不能可靠透视时改2D铰链模拟，不靠把旋转中心写成未经验证的草稿字段。
- **失败征兆与替代**：卡片绕中间转、背面镜像文字、边缘漏黑；改平面滑开。
- **区别/机制**：偏心支点 + 透视/平面翻转。原理依据见[来源P04](creative-sources.md#p04)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C32 推拉反向的Dolly Zoom

- **场景与素材前提**：想突出惊喜或空间变化；须相机实际前后移动且有背景深度、足够裁切余量。
- **实现路径**：M：相机后退时逐步数码放大，或前进时逐步缩小，使主体尺寸近似不变；纯静机位缩放不具备真实透视变化，不冒称Dolly Zoom。
- **失败征兆与替代**：主体忽大忽小、背景没变化、过度裁切变糊；改普通推近或不使用。
- **区别/机制**：真实位移 + 反向缩放。原理依据见[来源P08](creative-sources.md#p08)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C33 主体锁定与背景漂移

- **场景与素材前提**：主体在画幅内乱跑但需要围绕动作观察；需能跟踪的参照点与充足边缘。
- **实现路径**：M/X：跟踪主体运动，用反向位置/旋转把主体稳定在固定区域，再有意保留背景漂移；先裁切评估，成人头像与主体一起反向变换。
- **失败征兆与替代**：背景剧烈甩动、边缘放大、跟踪滑到遮挡物；只对一小段稳定或保留原运动。
- **区别/机制**：跟踪运动的逆变换。原理依据见[来源P04](creative-sources.md#p04)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C34 四角透视贴合

- **场景与素材前提**：绘画、地面、盒面或移动屏幕上要贴图文；需可跟踪平面与遮挡信息。
- **实现路径**：X：跟踪平面四角，把图文/视频作corner-pin，再恢复前景遮挡和适量曝光差；没有本机原生平面功能就用已安装辅助合成，主剪与终片仍回剪映。
- **失败征兆与替代**：图文像飘着、透视与接触面不符、遮挡时没消失；换静止平面或用非贴合标注。
- **区别/机制**：平面跟踪 + 四角映射 + 遮挡。原理依据见[来源P04](creative-sources.md#p04)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C35 冲击型阻尼震动

- **场景与素材前提**：落地、碰撞、拍手需要一次有重量的反馈；需准确动作瞬间、不是全程抖。
- **实现路径**：M：动作帧附近做短小的位置/旋转扰动，振幅逐步衰减；主体正常运动保留，把震动放在已遮挡画面整体上。
- **失败征兆与替代**：文字无法读、每个鼓点都抖、细节糊、头像滞后；只保留一次轻微缩放或取消。
- **区别/机制**：瞬态驱动 + 衰减振幅。原理依据见[来源P02](creative-sources.md#p02)；具体组合为本工作流的编辑设计，非原教程逐步转录。

## C36 跨剪点速度连续的虚拟运镜

- **场景与素材前提**：多张画面要像同一台相机经过；需共同方向、坐标参照和镜头余量。
- **实现路径**：M：给前镜末段和后镜首段统一运动方向及近似屏幕速度，切点不要两端同时ease到0；给整组规划起步与停步，内部保持流动。
- **失败征兆与替代**：每镜刹车再启动、速度折返、同向却无落点；改成一段持续平移或直接动作切。
- **区别/机制**：切点两侧速度匹配。原理依据见[来源P02](creative-sources.md#p02)；具体组合为本工作流的编辑设计，非原教程逐步转录。
