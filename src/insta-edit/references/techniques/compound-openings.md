# 概念开场与章节建立

本页属于[R01–R12组合配方](compound-recipes.md)，只加载目标条目。它们使用C/T基础能力组成完整设计，未新增“已经跑通”的API或预设；参数为分镜起点，真实执行先做难点样片。

<a id="r01"></a>

## R01 胶片长廊穿窗

**组合链**：胶片条错峰运动＋窗口蒙版＋前景遮挡＋同帧接管。

- **位置与动机**：开场或章节开始；几个真实事件要先被看见，再选一个深入。
- **素材门槛**：准备3–5段有明确差异的高质量短片、统一胶片边框与可分离的前景物件；不要求真的3D长廊。
- **图层（由上到下）**：上：前景手/物件；中：胶片框及各自窗口视频；下：简洁底色/环境。目标窗另备独立全分辨率正片，初始被框外背景遮住。
- **动作顺序与节奏**：0–0.8秒胶片条沿同一方向进入；0.8–1.8秒目标窗减速落定，其他窗继续错峰退出；1.8–3秒前景掠过框边，目标窗口扩展；3秒后框/底色撤掉，同源同帧正片继续。
- **实际路径**：先在剪映做平面胶片条与窗口位置/裁切关键帧；只有已验证透视工具可用才加纵深。选中格用独立全分辨率源完成放大，不放大总胶片预合成的小像素。框与内容共享变换。
- **质检与降级**：窗口内容滑出框、框先停内容仍动、正片突然变清/变糊、前景与头像不齐。缺透视就平面传送带；素材不足减到三窗，声音仅目标事件主轨。
- **调用基础能力**：[C01](advanced-openings.md#c01)、[C10](advanced-transitions.md#c10)、[C36](advanced-keyframes.md#c36)；原理来源随对应条目读取。

## R02 物件标本台变成故事

**组合链**：物件定格抠像＋逐段连线＋位置/旋转关键帧＋物件窗口接管。

- **位置与动机**：开场/探索章节；用玩具、叶片、小鞋等真实出现的物件建立主题。
- **素材门槛**：需要可读物件轮廓、取自原片的清楚静帧、对应物件后续行动镜头；背景简洁。
- **图层（由上到下）**：上：短标签与路径标记；中：物件抠像卡，目标卡有视频蒙版；下：纸纹或纯色台面。最终连续片先放在独立隐藏/被遮底层。
- **动作顺序与节奏**：0–1秒物件按行动先后错峰落台；1–2秒一条路径只连接当前主物件；2–3.5秒目标物件开出视频窗口，轮廓逐渐让位于真实场景；后续保留完整动作。
- **实际路径**：剪映用独立物件PNG、线段显隐和轨迹关键帧，复杂轮廓扩展才使用已验证本地预合成。目标卡的画面和最后全幅片匹配源时间，不随机挑一段好看素材。
- **质检与降级**：像商品广告堆满标签、物件与后续故事无关、蒙版在成人脸上开洞。减为两个物件或直接用物件近景；原声只在物件真的接触/落下时给反馈。
- **调用基础能力**：[C18](advanced-transitions.md#c18)、[C30](advanced-keyframes.md#c30)、[C40](advanced-overlays-pip.md#c40)；原理来源随对应条目读取。

## R03 线稿扫描唤醒实拍

**组合链**：实拍定格＋轮廓线描绘＋分区时间恢复＋前景正片叠加。

- **位置与动机**：开场/视角变化；“孩子发现世界”的绘画、手作或观察主题。
- **素材门槛**：一张清晰且已遮挡的关键帧、同镜头连续视频、可制作的轮廓线图；先确认本地描线路径或线段显隐可执行。
- **图层（由上到下）**：上：已遮挡的活主体；中：逐段出现的线稿与恢复视频的区域蒙版；下：纸面/色板。视频由区域遮罩逐步露出，不能整屏降透明度露底脸。
- **动作顺序与节奏**：0–0.8秒少量线条先交代物件；0.8–2秒扫描边界让对应区域由线稿变实拍；2–3秒主体先动、背景最后恢复；3秒后全部回连续正片。
- **实际路径**：为每个恢复区域列出冻结源帧、开始播放的源时间、时间轴恢复点与最终接管点；描线和恢复蒙版共用该表。主体开始活动前撤掉该区域旧姿势线稿，不能把活动人物叠在另一时刻的同一人物轮廓上。剪映无可靠路径描绘就用有限线段或已验证的本地透明描线片，复杂波动扫描才走X路线。不使用云AI补出未拍内容。
- **质检与降级**：轮廓图和视频错位、手已经动线稿还停旧姿势、背景恢复后跳帧。只画一件静止物并一次揭示；没有线图就删掉线稿，保留有动机的局部恢复。
- **调用基础能力**：[C03](advanced-openings.md#c03)、[C26](advanced-freeze-time.md#c26)、[C30](advanced-keyframes.md#c30)；原理来源随对应条目读取。

## R04 字组成跑道，主角穿字入场

**组合链**：动作轨迹＋逐词排版＋主体前后遮挡＋跨剪点运动接力。

- **位置与动机**：开场/人物第一次行动；跑、跳、伸手有明确移动方向，适合活跃创意版。
- **素材门槛**：选择留白足的连续动作，主标题短；文字位置依据画面路径设计，不能挡眼神/脚落点。
- **图层（由上到下）**：上：主体前景＋同主体动物头像；中：沿空间排布的词/标记；下：完整V_safe。某些字可在主体后、某些字前，但层次按真实遮挡关系确定。
- **动作顺序与节奏**：0–0.7秒动作先发起；0.7–1.8秒关键词依次被动作带出；1.8–2.8秒最后一词沿动作方向离场，接下一镜同向运动；随后让动作完整展开。
- **实际路径**：剪映分词图层＋位置/旋转关键帧；用前景副本盖住字，前景和底片完全同源同帧。没有透视跟踪时保留平面图形语法，不把字幕伪贴在真实地面。
- **质检与降级**：每字都跳导致抢戏、词的顺序读反、遮挡断开、下一镜反向。减少到两个词；跟踪不稳就用固定留白排字，保留动作切。
- **调用基础能力**：[T03](typography-and-motion.md)、[C30](advanced-keyframes.md#c30)、[C36](advanced-keyframes.md#c36)；原理来源随对应条目读取。
