# 纯动物头像与成人遮挡

所有可辨成人用可爱的纯动物3D头部遮住，孩子保留真实面部。动物资产由本skill的 `assets/` 管理。

## 动物资产与坐标

assets 内三张透明 PNG 是已生成的纯动物头部，可直接复制进项目。先确认 alpha 和脸部区域；图片中心不等于口鼻中心。

| 动物 | 动物脸部锚点（图片归一化） | 起始尺寸经验 |
|---|---|---|
| 熊猫 | (0.50,0.55) | 边长取成人脸高1.95倍或宽2.15倍中足够覆盖者 |
| 狐狸 | (0.49,0.62) | 边长约脸高2.25倍或宽2.3倍 |
| 兔子 | (0.50,0.74) | 长耳图边长约脸高2.95倍 |

仅适配所附资产，不保证新头像通用。验收标准是真实成人脸持续完整遮住，不是参数达到某值。 头像外接框覆盖人脸不代表实际alpha覆盖：狐狸两耳之间、下缘及旋转边缘可能透明，额头也必须被不透明动物头部覆盖。亲子重叠时检测器漏掉成人，不能把附近孩子框自动接成成人轨迹；轨迹突降、尺寸突跳、身份置信度不足时回看源帧并手动修正/弃用，不能仅按空间距离选最近检测框。

YuNet 可检测候选，CSRT/光流辅助跟踪，人工确认成人种子并双向跟踪、补关键帧；切镜头重置轨迹。儿童不遮，建筑/海报误检不贴。夜景与画面边缘侧脸易漏检，必须看真实图像。

每个选中镜头先看完整画面，列出前景和背景中的可辨成人，再选跟踪目标；首尾、手指遮镜和前景遮挡变化处尤其容易短暂露出未入轨迹的背景侧脸。头部crop只能证明所截区域，不能代替整幅画面中其他成人的检查。低清参考升到4K重构后，用实际编码的完整帧与原像素背景局部复检，不能因旧头像轨迹没变就沿用全片隐私结论。只有发缘或身体、无可辨五官的区域应如实描述，不把它扩编成已确认漏脸。

成人在孩子后面时，前景蒙版限定于孩子真实轮廓；过大椭圆可能还原成人脸。头像前后关系和儿童眼睛、手、头发附近逐帧看。成人进出画、快转、运动模糊加余量，跟不稳就裁掉或弃片。


## 可重建记录

保存源时间码、取景参数、头像轨迹、资产和工程依赖；按镜头高质量处理，避免满盘中间片。实际时间轴与导出使用剪映，详见 [本机兼容性](jianying-compatibility.md)。云备份遵循总流程的唯一文件名核对，不为恢复测试重复下载。
